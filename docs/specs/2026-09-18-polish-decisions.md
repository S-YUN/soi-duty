# 3차 — 실사용 다듬기 + 스플래시 (결정 기록)

작성일: 2026-09-18
선행: `docs/specs/2026-09-17-week-month-sheet-design.md`. 규칙 반영본은 `CLAUDE.md`(이 문서는 "왜"만 남긴다).
디자인 원본: `docs/specs/design-handoff-3-splash-icon.md`(스플래시·아이콘), 월간 캘린더·미래 시트는 사용자 목업(대화 중 전달).

## 결정과 이유

| 결정 | 이유 |
|---|---|
| 주간 타이틀 "n월 n째주", 목요일 기준 달 | 날짜 범위보다 짧고 읽기 쉽다. 두 달 걸친 주는 KS X ISO 8601 관례를 따른다. |
| 월간 범위 상한 = 올해 12월 | 연차·공휴일을 연말까지 미리 찍기 위해. 해 바뀌면 자동으로 새해 12월. |
| 달 이동은 화살표만, 캘린더 스와이프 제거 | 만들어 봤더니 탭 스와이프와 겹쳐 어색. 화살표를 키우고 타이틀 가까이 붙였다. |
| 반차 = 연차·공휴일과 같은 규칙 (미래 미리 가능) | 미래 반차는 찍는 순간 그 주 목표를 4h 줄인다 — 연차와 같은 계획 도구. 오늘만 허용하면 그 정보를 잃는다. |
| 퇴근 전 오늘은 주간·월간에서 편집 불가 → 토스트 | 오늘 기록은 오늘 화면 버튼이 찍는다. 이동시키는 대신 자리에서 이유를 알려준다. |
| 연차·공휴일 칩 즉시 저장, 취소 버튼 제거 | 시각 입력이 없는 유형은 두 번 누를 이유가 없다. 닫기는 내리기·바깥 탭으로 충분. 시각 있던 날만 확인 한 번. |
| 휠 오전/오후 · 1–12, 기본 08:00/17:00 | 24시간 휠은 돌리는 게 수고스럽다. 기본값은 시트 안에서만, 저장·표시엔 관여 안 함. |
| 오늘·주간 첫 카드 단순화 | 오늘은 잔여 숫자 하나에 집중, 실적/목표 세부는 주간에. 주간은 실적/그 주 목표 + 연반공 개수만. |
| 월간 캘린더 원 스타일, 오늘 표시 없음 | 배지·셀 박스보다 낮고 한눈에 들어옴. 일반 근무일 원 색은 하나로(색이 많으면 산만). 오늘 테두리는 은은하게 해도 거슬려 제거. |
| 경과 표시 분 단위 유지 | 초 단위도 부담 없지만 필요성이 없었다. |
| 스플래시는 네이티브만, 준비까지 preserve | 인앱 스플래시는 같은 화면을 두 번 보여주는 셈. 로컬 DB라 기다릴 것도 없어 대기 바도 번쩍임만 된다. 인위적 지연 없음. |
| 토스트는 자체 오버레이 | 기본 SnackBar는 톤이 안 맞고, 패키지는 색·글꼴이 따로 논다. 브랜드색 85% 알약. |

## 알아둘 것

- flutter_driver의 `screenshot()`은 오버레이 토스트를 담지 못한다. 시뮬레이터 `simctl io screenshot`으로 확인했다.
- 드라이버는 상태 변경 직후 `waitUntilNoTransientCallbacks`가 애니메이션 시작 전에 통과할 수 있다. 화살표 탭 뒤엔 타이틀 갱신을 먼저 기다린다.
- `flutter_native_splash`는 `preserve/remove`를 런타임에 쓰므로 일반 의존성이다.

## 이어진 결정 (2026-09-25)

| 결정 | 이유 |
|---|---|
| 근무 중 "출근 변경" 시트 추가 | 출근하고 10분 뒤에 찍는 일이 흔한데, 오늘 편집을 퇴근 후로 잠그면서 고칠 길이 없어졌다. 출근 시각만 다루는 작은 시트로 열고, 지금보다 늦은 시각은 막는다. |
| 퇴근 완료 상태에서 제목 제거·요약 박스 제거 | "오늘 기록 완료"는 버튼이 이미 말한다. 요약은 배경 없이 구분선만 두고 값을 18로 키워 한눈에 읽히게. |
| 캘린더 값은 얇은 공백으로 | `+3h 52m`(47.1px)이 칸(43.6px)을 넘어 조용히 잘리고 있었다. 공백을 빼는 대신 얇은 공백(U+2009)·비례 숫자·좁은 자간을 합쳐 43.2px로 만들어 **공백과 글자 크기를 유지**했다. 대가는 캘린더 값에서만 숫자 고정폭 해제. |
| 글자 크기 전반 상향 (2차) | 주간 메모·요일·± 값, 캘린더 날짜, 범례, 시트 칩·휠 제목 등. 실기기에서 작게 느껴졌고, 가로·세로 여유를 재보니 넘칠 데가 없었다. |
| 메모 줄을 고정 높이 박스로 | 최소 높이로 두면 빈 메모(19px)와 글자가 든 메모(20px)의 줄 높이가 달라 7행 높이가 1px 어긋난다. 글꼴을 바꿔도 안 깨지게 구조를 바꿨다. |
| 기록 안 된 날 오래된 순 | 채우는 순서가 시간 순이고, 오래된 누락일수록 기억이 흐리다. |
| 첫 기록 전 날들은 첫 주만 노출 | 첫 주는 목표가 없어 그 날들이 어떤 계산에도 쓰이지 않는다. 계속 조르면 "채우지 않아도 다음 주부터 계산된다"는 안내가 거짓이 된다. |

## 알아둘 것 (측정값)

- 월간 셀: 7칸이 쓸 수 있는 폭 **322.6px**(화면 여백 20 + 카드 안쪽 14 뺀 값). 열 간격 2에서 칸 **44.4px**.
  `+3h 52m` 47.1 / 자간만 45.3 / 비례 숫자+자간 44.6 / **얇은 공백까지 43.2**. 공백을 유지하려면 세 수단이 다 필요하다.
- 주간 행: 가운데 칸 **226.8px**, 가장 긴 메모("주 40시간 제외 · 10:00 – 14:30")가 13pt에서 167.8px. ± 칸은 76px.
- `.w`와 `.sp`가 같은 배율이라 폭이 다른 기기에서도 비율이 유지된다. SizeConfig 상한(480) 위에서는 칸만 넓어져 더 안전하다.
  폭 320~600 8종을 테스트로 고정했다.
- flutter_driver의 `screenshot()`은 오버레이 토스트를 담지 못한다. 토스트 모양은 `simctl io screenshot`으로 본다.
- 드라이브는 캘린더 셀을 `calendarCellKey`로 집고 과거·미래 평일을 실행 시점에 고른다 — 날짜를 하드코딩하면 날이 바뀔 때 깨진다.
