이 문서는 `README.md`(오늘 화면 핸드오프)의 **후속**이다. 색상·타이포·간격 토큰, 폰트(Pretendard, tabular figures), 레이아웃 원칙은 모두 `README.md`의 값을 그대로 쓴다. 여기서는 새로 추가되는 화면과, 오늘 화면에서 **변경된 부분만** 적는다.

구현 순서 권장: ① 오늘 화면 변경분 → ② 시간 수정 시트(주간·월간·오늘에서 공유) → ③ 주간 → ④ 월간.

## 0. 오늘 화면 변경분 (이미 구현한 화면의 수정 사항)

보조 슬롯(주 버튼 아래 40 고정 높이)의 내용이 바뀌었다. **`README.md`의 보조 슬롯 표를 아래로 대체한다.**

### 공통 스타일 — 조용한 텍스트 버튼
보조 슬롯의 액션은 박스가 없는 텍스트 버튼이다. 배경·테두리 없음.
- 13px / w500 / `#2C5A4C`
- 탭 영역 확보용 패딩 `8 4` (실제 히트 영역은 최소 44 높이로 확장)
- pressed: `opacity: .55`
- 두 개가 나란히 설 때는 사이에 1×11 구분선 `#DCDFD8`, 항목 간 gap 16

### 상태별 보조 슬롯
| 상태 | 보조 슬롯 내용 |
|---|---|
| 출근 전 | 라디오형 체크 2개 — "오늘은 연차" / "오늘은 공휴일" (gap 18) |
| 근무 중 | 체크박스 "오늘은 반차" · 구분선 · 텍스트 버튼 **"출근 취소"** |
| 퇴근 완료 | 텍스트 버튼 **"시간 수정"** · 구분선 · 텍스트 버튼 **"퇴근 취소"** |
| 연차/공휴일 | 텍스트 버튼 **"되돌리기"** (단독, 가운데) |
| 첫 주 예외 | 체크박스 "오늘은 반차" · 구분선 · "출근 취소" (근무 중과 동일) |

연차/공휴일 상태의 보조 슬롯에서 **"기록하려면" 안내 문구는 삭제**했다 — 상태 블록이 이미 "근무 기록은 남기지 않습니다"를 말하므로 중복.

### 동작
- **출근 취소** (근무 중 → 출근 전): 실수로 출근을 찍은 경우. `phase = before`, `clockInAt = null`, **반차 체크도 함께 해제**(`isHalfDay = false`).
- **퇴근 취소** (퇴근 완료 → 근무 중): `phase = working`, `clockOutAt = null`. 오늘 근무를 다시 진행 중으로 되돌린다.
- **시간 수정** (퇴근 완료): **퇴근을 풀지 않고** 오늘 기록을 담은 시간 수정 시트를 연다(§2). 기록된 출근/퇴근 시각을 그대로 들고 열린다.
  - 이전 버전에서 "시간 수정하기"가 퇴근 상태를 풀어버렸는데, 그건 버그다. 기록된 값을 앞으로 당기거나 미루는 것이 이 버튼의 목적이고, 퇴근 자체를 취소하는 건 옆의 "퇴근 취소"가 맡는다.
- **주 버튼은 퇴근 완료 상태에서 완전히 무반응**이다. 탭해도 아무 전이도 일어나지 않는다(출근 전으로 돌아가지 않는다). 되돌리는 경로는 "퇴근 취소"뿐.
- **되돌리기** (연차/공휴일 → 출근 전): `dayType = null`.

### 브랜드 표기
화면 어디에도 "SOI DUTY" 워드마크를 넣지 않는다. 목업에서 상단/하단에 잠깐 넣어봤지만 모두 제거했다. 필요하면 구현 단계에서 판단.

## 2. 시간 수정 시트 (bottom sheet)

주간 리스트의 날짜 행, 월간 캘린더 셀, 빵꾸 리스트 행, 오늘 화면의 "시간 수정" — **네 진입점이 모두 이 시트 하나를 공유한다.**

### 시트 껍데기
- 스크림: `rgba(22,25,26,.42)`, 페이드 인 `.18s ease-out`. 탭하면 닫힘(저장하지 않음)
- 시트: 하단 고정, 배경 `#FCFCFB`, radius `24 24 0 0`, 패딩 `10 20 30`, 그림자 `0 -8 34 rgba(22,25,26,.18)`
- 등장: `translateY(100%) → 0`, `.26s cubic-bezier(.22,.8,.3,1)`
- 그랩 핸들: 38×4, radius 999, `#DCDFD8`, 가운데, 하단 margin 14

### 내용 (위→아래)
1. **날짜 제목** — 16px / w600 / ls −0.01em. 예: "9월 11일 금요일". 신규 기록이면 "기록 추가"
2. **주말 안내** (주말 날짜일 때만) — 배경 `#F0F2ED`, radius 11, 패딩 `11 13`, 11.5px `#5F6559`, lh 1.5: "주말 근무는 주 40시간에 포함되지 않아요"
3. **유형 선택** (주말 아닐 때만) — 3열 그리드, gap 7, margin `14 0 4`. 칩: 반차 / 연차 / 공휴일. 미선택은 중립 톤, 선택 시 해당 유형 색(README의 배지 색상표)으로 채움. **서로 배타적, 재탭으로 해제**
4. **출근 행 / 퇴근 행** — `Row`, 좌측 라벨 13px `#5F6559`, 우측 시각 20px w500. 행 패딩 `15 12`, 좌우 margin −12, radius 12, 하단 구분선 1px `#E7E9E3`
   - **행 전체가 탭 영역.** 탭하면 그 행이 선택되고(배경 `#F1F3EE`, 시각 w600 `#2C5A4C`) 바로 아래에 시각 선택 휠이 펼쳐진다. 같은 행 재탭으로 접힘
5. **시각 선택 휠** (행 선택 시에만)
6. **계산 내역** — 12.5px, lh 1.9. 행: 근무 / 점심 공제 / 기준 / 기준 대비. 주말이면 근무 · 점심 공제("없음") 두 줄만
   - 점심 공제: 반차면 "없음 (반차)", 아니면 "1h 00m"
   - 기준: 반차 "4h 00m", 아니면 "8h 00m"
   - 기준 대비: 마지막 줄, 값에 색(음수 `#A8503F` / 양수 `#2C5A4C`)
7. **취소 / 저장** — 2열 그리드 **1:1**, gap 9, 상단 margin 20. 각 **높이 52 고정**, radius 13, 15px w600
   - 취소: 배경 `#F0F2ED`, 글자 `#5F6559`, pressed `#E7EAE4`
   - 저장: 배경 `#2C5A4C`, 글자 `#F4F6F3`, pressed `#24483E`
   - (이전에 1:1.5 비율이었는데 1:1로 확정)
8. **이 날 기록 지우기** — 상단 margin 16, 가운데, 12.5px `#5F6559`. 탭하면 확인 후 해당 날짜 기록 삭제

### 시각 선택 휠
iOS 계열 스크롤 휠. Flutter에서는 `CupertinoPicker` 2개(시/분) 또는 `ListWheelScrollView`로 구현한다.

- 전체 높이 **176**, 항목 높이 **44** (선택 밴드 높이와 동일)
- 선택 밴드: 가운데에 흰색(`#FCFCFB`) radius 11 띠를 깔고 `pointerEvents: none`
- 두 컬럼(시 / 분) 사이에 20px w600 콜론 `:`
- 위아래 페이드: `linear-gradient(transparent, #000 32%, #000 68%, transparent)` 마스크
- 시: **0~23**, 분: **0~59 (1분 단위)**. 둘 다 2자리 zero-pad
- 선택 항목 25px w600 `#16191A`, 비선택 20px w500 `#9DA296` — 전환 `.12s`
- 스크롤 스냅(`scroll-snap-align: center`), 항목 직접 탭으로도 선택 가능
- **열 때 기존 값 위치로 스크롤해야 한다** (`scrollTop = index * 44`). 기록이 있으면 그 값, 없으면 **00:00**에서 시작
- 프리셋 버튼은 없다 (09:00 / 09:30 같은 고정값 칩을 넣었다가 뺐다 — 실제 출퇴근 시각은 09:12처럼 임의값이라 도움이 안 됨)

### 카드 B — 일별 리스트 (7행)
배경 `#FCFCFB`, radius 20, `overflow: hidden`, 카드 자체 패딩 없음. 행이 카드 폭을 꽉 채운다.

| 영역 | 사양 |
|---|---|
| 날짜 | **폭 30 고정, 가운데 정렬.** 숫자 15px w500 lh 1.15 / 요일 11.5px, 숫자 아래 margin 1. 주말은 둘 다 `#8B9184` |
| 내용 | `Expanded`, min-width 0. 상단: 근무시간 15px w500(+ 유형 배지). 하단: 보조 11.5px `#5F6559`, 상단 margin 3, **min-height 16** |

- 상태별 표기: 기록 있음 `8h 31m` + `09:05 – 18:36` / 진행 중 `근무 중` + `09:12 출근`, 값은 `—` / 미기록 `—` / 주말 `4h 30m` + `주 40시간 제외 · 10:00 – 14:30`, 값 없음

## 4. 월간 탭

기간 네비게이터(§1) 아래: 캘린더 → 범례 → 리포트 진입점 → (펼침) 리포트 카드들.

### 카드 A — 캘린더
- 배경 `#FCFCFB`, radius 20, 패딩 `16 14 16`
- 상단 라벨: 가운데, 12.5px w500 `#5F6559` — "기준 대비 ±" (셀에 무엇이 적혀 있는지 알려주는 헤더)
- 요일 헤더: 7열 그리드, 패딩 `14 2 6`, 각 10.5px `#5F6559` 가운데. **월 화 수 목 금 토 일** (월요일 시작)
- 날짜 그리드: **`repeat(7, minmax(0, 1fr))`**, gap `4 3`, 좌우 패딩 2
- 셀: **높이 58 고정**, radius 10, 세로 `Column`, 가운데 정렬, **`justifyContent: flex-start` + `paddingTop: 9`**, gap 5, `minWidth: 0`, `overflow: hidden`
  - **셀 내부를 세로 중앙 정렬하면 안 된다.** 값이 없는 날(숫자만 있는 날)의 숫자가 중앙으로 내려와 같은 행의 다른 날과 줄이 어긋난다. 위쪽 고정 배치 + paddingTop 9로 모든 셀의 날짜 숫자가 같은 y에 온다.
  - `minmax(0,1fr)`와 `minWidth: 0`이 없으면 `+1h 12m` 같은 긴 값이 그 열을 밀어 열 폭이 틀어진다.
- 셀 내용: 날짜 숫자 10.5px `#5F6559`(이번 달 아님/주말은 `#C3C7BE`) → 유형 배지(있으면) → 기준 대비 값(있으면)
  - 배지: 패딩 `1 5`, radius 4, 10px w700, 유형 색
  - 값: 11.5px w500(주말 11px w400), 색 규칙은 주간과 동일
  - 기록 있는 평일 셀은 배경 `#F1F3EE`, 이번 달 아님/주말은 투명
- 셀 탭 → §2 시트

### 범례
캘린더 아래, 패딩 `2 6 0`, wrap `Row`, gap `8 14`, 11.5px `#5F6559`. 항목: 13×13 radius 4 색상 칩 + 라벨 — 반차 `#E5DCBB` / 연차 `#DFD2DD` / 공휴일 `#E6CFC6`

### 리포트 진입점
- **배경 `#E1E4DD`(화면 톤), radius 16, 패딩 `14 18`, 그림자 없음.** 흰 카드로 만들면 캘린더보다 강해 보여서 톤을 내렸다 — 캘린더가 이 탭의 주인공이고 리포트는 부가 정보다.
- 좌측 "이번 달 리포트" 13.5px w600 `#5F6559` / 우측 셰브론
- 셰브론은 글리프(⌄)가 아니라 **CSS 도형**으로 그린다: 8×8 박스의 오른쪽·아래 테두리 1.7px `#5F6559`, 접힘 `translateY(-2px) rotate(45deg)`, 펼침 `translateY(1px) rotate(225deg)`, 전환 `.2s ease`. (글리프는 폰트 baseline 때문에 세로 중심이 맞지 않는다)
- 탭하면 아래 카드들이 펼쳐진다. 기본은 접힘.
