# 디자인 브리프 6: SOI DUTY — 시간 출장 기록 · 퇴근 알림

작성일: 2026-11-20 (1부는 같은 날 "시간 출장(계산 반영)"에서 "시간 출장 기록(계산 미반영)"으로 바꿈)
대상: Claude Design (핸드오프 1~5를 만든 쪽)
선행 핸드오프: Handoff 2(주간·월간·시트), Handoff 4(설정 화면), Brief 5(남은 연차). 토큰·글꼴·간격은 그대로 따른다.
이 문서는 **새로 필요한 화면·상태와 문구**만 적는다. 계산 규칙은 정해져 있고, 화면과 문장을 부탁한다.

- 1부 **시간 출장 기록**: "몇 시부터 몇 시까지 출장"을 남기고 보여준다. 계산에는 안 쓴다.
- 2부 **퇴근 알림**: 화면은 작다(권한 묻기·설정 행). **알림 문구 구상**이 주 작업이다.

# 1부. 시간 출장 기록

## 0. 왜

- 요청: "출장 시간을 입력할 수 있으면 좋겠다 (ex 3시간 출장, 나머진 정상 근무)".
- 시간 계산은 이미 된다. 출장 출발할 때 출근을 찍고, 돌아와서 일이 끝날 때 퇴근을 찍으면 평범한 근무일과 같다.
  예: 09:00 출근(출장 출발) → 12:00까지 출장 → 사무실 복귀 → 18:00 퇴근. 점심도 평소대로.
- 사용자가 원하는 건 **"오늘 09:00–12:00 출장이었다"는 기록이 남는 것**이다.

## 1. 개념 (정해진 것)

- **종일 출장**: 지금 그대로. 쉬는 날, 시각 없음, 8h 인정. 화면도 그대로.
- **시간 출장**: 근무한 날에 붙는 **출장 시작·끝 시각 범위**. 하루에 하나.
  **계산에 전혀 영향이 없다** — 잔여·기준 대비·점심·알림 모두 출퇴근으로만 계산한다. 범위는 기록하고 보여주기만 한다.
- 평일뿐 아니라 **주말 근무·공휴일 근무에도** 붙는다. 미래 날짜(미리 아는 출장), 지난 날짜, 오늘 모두 넣을 수 있다.
- 검증은 **끝 > 시작** 하나. 출퇴근 구간 안에 있어야 한다는 제약은 두지 않는다(계산에 안 쓰니 겹쳐도 문제없다).
  근무 중에 넣으면 끝이 아직 오지 않은 시각이어도 된다(예정).

## 2. 입력 — 맡긴다

- 시트(미래 · 출근 전 오늘 · 과거)와 오늘 화면 중 어디에 어떻게 둘지 제안해 달라.
- 시각 입력은 출퇴근 휠(오전/오후 · 시 · 분)을 쓰고, **큰 시트 안에 휠을 펼치지 않는다** — 시간공제처럼 작은 시트를 겹쳐 띄운다
  (큰 시트 안에 펼쳤더니 화면을 넘어 시트가 안 닫힌 이력). 시작·끝 두 휠의 배치, 처음 값(예: 09:00–12:00)은 제안해 달라.
- 끝 ≤ 시작일 때의 안내 상태가 필요하다.
- 넣은 범위를 고치기·지우기 길도 필요하다.
- **조건: 근무 중에도 넣을 수 있어야 한다.** 퇴근한 뒤에야 넣을 수 있는 구조는 안 된다.
  지금 근무 중엔 주간·월간 시트가 잠겨 있다("오늘 기록은 퇴근한 뒤에 수정할 수 있어요") — 오늘 화면 어딘가에 길이 필요하다.
  근무 중 보조 슬롯은 이미 "☐ 오늘 반차 · 출근 변경 · 출근 취소" 셋이 차 있고, 상태 블록엔 "☐ 남은 시간 공제하고 퇴근"이 있다.
- 종일 출장(유형)과 시간 출장이 시트에서 헷갈리지 않아야 한다. 지금 시트의 출장 칩/행은 종일 출장이다.

## 3. 보이는 곳 — 오늘 · 주간 · 월간 모두

- **오늘**: 출근 전·근무 중·퇴근 완료 상태에서 출장 범위가 어떻게 보일지.
- **주간**: 행에 출장 범위(예: "출장 09:00–12:00")를 어떻게 보일지 — 배지인지, 시각 줄인지. 반차·공제 배지와 함께 붙을 수 있다 —
  7행 높이가 모두 같아야 한다(폭 320·360·600).
  첫 카드 요약 줄 "출장 n"은 **종일 출장 + 시간 출장 날을 모두 1로 센다** (정해짐).
- **월간**: 시간 출장 날도 **날짜 원을 출장색**(`#D3DDE3`/`#3F5866`)으로 (정해짐). 셀 값은 평소 근무일과 같다. 범위는 캘린더에 안 쓴다.
  반차 + 출장, 공휴일 근무 + 출장인 날의 원 색(반차색·공휴일색 / 출장색)은 제안해 달라. 범례를 바꿀 필요가 있는지도.
  주말 근무 + 출장이면 출장색 원 위의 날짜 숫자 색도(지금 주말 숫자는 원 위에서도 적갈색).
- **시트**: 과거 시트 계산 내역에는 넣지 않는다(계산과 무관). 시트 어딘가에 범위가 보이면 된다.

# 2부. 퇴근 알림

## 6. 왜 · 무엇

- 요청: "퇴근할 때 되면 알림 → 워치에도 오게끔".
- **1차는 정시만.** 그날 채울 시간을 다 채운 시각, 또는 이번 주를 다 채운 시각에 한 번. 10분 전 같은 예고 알림은 없다.
- 알림에 버튼("퇴근하기")은 없다. 출퇴근은 오늘 화면에서 찍는다.
- 워치 앱은 없다. 폰 알림이 OS를 통해 워치로 간다 — **워치 작은 화면에서 제목만 보고도 뜻이 통해야 한다.**
- **알림 하나 = "이제 가도 돼요".** "아직 남았어요" 같은 알림은 보내지 않는다. 알림이 안 온 것 자체가 "아직"이다.

## 7. 화면 (작다)

### 7-1. 권한 묻기 — 첫 "출근하기"를 누를 때 한 번

- 설치 직후가 아니라 **처음 출근 버튼을 누를 때** 묻는다. iOS는 한 번 거절하면 다시 물을 수 없어서, 맥락이 있을 때 묻는다.
- 다이얼로그인지 시트인지 제안해 달라. 수락하면 바로 OS 권한 창이 뜬다. 출근은 수락·거절과 상관없이 찍힌다.
- **거절 직후 토스트**(기존 브랜드색 알약): "설정에서 언제든 켤 수 있어요" 같은 한 줄. 다시 묻지 않는다.

### 7-2. 설정 "알림" 섹션

- 기존 섹션들과 같은 골격의 행 하나: 켜기/끄기.
- **이 앱에 토글이 처음 들어온다.** 연차·수당은 "값을 넣으면 켜지는" 방식이라 토글이 없었다. 토글을 쓸지, 다른 방식이 나은지 제안해 달라.
- 섹션 순서 제안도 부탁한다 (지금: 캘린더 · 연차 · 수당 · 데이터 · 앱 정보).
- 상태 세 가지: **켜짐 / 꺼짐 / OS 권한이 꺼져 있음.**
  세 번째는 앱에서 켤 수 없고 OS 설정으로 보내야 한다 — 행이 어떻게 보이는지, 누르면 무엇이 뜨는지(안내 + "설정 열기").

## 8. 문구 — 케이스는 정해짐, 문장을 부탁

케이스 분류는 끝났다. **문장만** 구상해 달라. 아래 예시는 자리 표시일 뿐이다. 톤은 기존 안내 문구
("드디어 금요일! 오늘도 힘내세요", "이번 주 페이스 좋아요")와 맞춰 달라.

### 8-1. 알림 (제목 + 본문)

| # | 언제 | 상황 | 예시 (임시) |
|---|---|---|---|
| **N1** | 그날 채울 시간을 다 채운 시각 | 월~목 같은 평범한 날. 반차(4h 뒤)·시간공제·시간 출장·첫 주인 날도 **같은 문구** | "퇴근할 시간이에요!" |
| **N2** | 이번 주 목표를 다 채운 시각 | 주로 금요일(마지막 근무일). 앞선 날 많이 일했으면 8h 전에, 덜 일했으면 8h 뒤에 온다. 이 날은 N1이 안 간다 | "이번 주 다 채웠어요" |
| **N3** | 위 시각이 이미 지나서 바로 보낼 때 | 출근 시각을 앞으로 고쳤더니 퇴근 시각이 이미 지난 경우 등. **N1·N2와 같은 문구로 갈지, 따로 둘지도 판단해 달라** | "퇴근 시간이 지났어요" |

- N1과 N2는 같은 날 둘 다 오지 않는다. 하루에 알림은 최대 하나.
- N2는 금요일이 아니어도 마지막 근무일이면 온다(금요일이 연차면 목요일). 기존 안내 문구처럼 "금요일"을 쓰려면 아닌 날의 대안도 필요하다.
- 숫자(시각·남은 시간)를 넣을지는 맡긴다. 넣는다면 어떤 값인지 적어 달라.

### 8-2. 권한·설정

| # | 위치 | 필요한 문구 |
|---|---|---|
| **P1** | 첫 출근 때 묻는 화면 | 제목 · 설명 · 수락 · 거절 (예: "퇴근 시간에 알려드릴까요?") |
| **P2** | 거절 직후 토스트 | 한 줄 (예: "설정에서 언제든 켤 수 있어요") |
| **P3** | 설정 "알림" 섹션·행 | 섹션 제목 · 행 제목 · 보조 설명(켜짐/꺼짐 각각) |
| **P4** | OS 권한이 꺼진 상태 | 행 보조 설명 + 눌렀을 때 안내 + 버튼 |

### 8-3. 알림이 가지 않는 경우 (문구 불필요, 참고용)

주말·공휴일 근무, 연차·종일 출장 같은 쉬는 날, 출근 전에 이미 이번 주를 다 채운 주, 다 채우기 전에 퇴근한 날("공제하고 퇴근" 포함).

## 9. 제약

- 브리프 4 §4 그대로: 폭 320~600, SafeArea, 글자 최소 11.5, 토큰 안의 색.
  유형 색은 같은 뜻으로만 쓴다 — 출장 청회 `#D3DDE3`/`#3F5866`, 공제 중립 `#E6E8E2`, 선택 행 배경 `#DDE8E1`.
- 시트는 큰 시트 위 작은 시트 겹침 구조를 유지한다. 큰 시트 안에 휠을 펼치지 않는다.
- 산출물: `.dc.html` + 토큰 설명. 필요한 상태:
  - **시간 출장**: 입력 길(시트 · 오늘 화면 근무 중) · 범위 작은 시트(정상 / 끝 ≤ 시작) · 오늘 화면 출근 전/근무 중/퇴근 완료 ·
    주간 출장 행 · 배지 여럿 붙은 행 · 요약 줄 · 시간 출장 날이 섞인 월간
  - **알림**: 권한 묻기 화면 · 거절 토스트 · 설정 알림 행 세 상태 · OS 설정 안내 · 알림 문구 표(N1~N3, P1~P4)

## 10. 정리 — 정해진 것 / 열어둔 것

| 정해진 것 | 열어둔 것 (디자인에서 제안) |
|---|---|
| 시간 출장 = 시작·끝 범위 기록, 하루 하나, 계산 영향 없음 | 입력 길 전부 (근무 중에도 가능해야 함) |
| 검증은 끝 > 시작 하나, 출퇴근과 겹쳐도 됨 | 시작·끝 휠 배치, 처음 값 |
| 주말·공휴일 근무에도 붙음 | 종일 출장과 헷갈리지 않게 하는 법 |
| 종일 출장은 지금 그대로 | 오늘 화면·주간 행에서 범위를 보이는 모양 |
| 오늘·주간·월간 모두 보임, 주간 요약 "출장 n"은 시간 출장도 1 | 반차·공휴일 + 출장 날 월간 원 색, 범례 |
| 월간 원은 시간 출장 날도 출장색, 범위는 캘린더에 안 씀 | |
| 알림은 정시만, 하루 최대 하나, 버튼 없음 | 권한 묻기: 다이얼로그 vs 시트 |
| 권한은 첫 출근 때 한 번, 거절 시 토스트 | 설정 알림 행: 토글 여부, 섹션 위치, OS 권한 꺼짐 상태 |
| 알림 케이스 N1~N3, P1~P4 | 모든 문구, N3를 따로 둘지 |
