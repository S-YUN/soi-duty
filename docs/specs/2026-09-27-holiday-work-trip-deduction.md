# 공휴일 근무 · 출장 · 시간공제 (2026-09-27)

친구 실사용 피드백 세 건. 모두 계산 규칙이 바뀌므로 CLAUDE.md "계산 규칙"도 함께 고친다.

1. 공휴일로 찍은 날에도 일할 수 있다 — 주말 근무처럼 계산한다.
2. 출장 유형 추가 — 연차처럼 8h 공제.
3. 시간공제 — 연차·반차로 안 되는 시간(예: "오늘 2시간 일찍 퇴근" 공문)을 직접 넣어 그날 기준시간에서 뺀다.

---

## 1. 데이터 모델

```dart
enum WorkType { normal, halfDay, dayOff, holiday, businessTrip }

WorkRecord(
  date, clockIn, clockOut, type,
  @Default(0) int deductionMinutes,   // 시간공제. 0이면 없음
  String? deductionReason,            // 선택. deductionMinutes가 0이면 저장하지 않는다(null)
)
```

- 시간공제는 **유형이 아니라 그날에 붙는 값**이다. 반차와 함께 쓸 수 있다.
- 시간공제를 가질 수 있는 날: **평일 && 유형이 normal 또는 halfDay.** 연차·공휴일·출장·주말은 0으로 저장한다
  (유형을 그쪽으로 바꾸면 공제·사유가 지워진다).
- 공휴일은 이제 `clockIn`·`clockOut`을 가질 수 있다. 연차·출장은 여전히 `null`.
- `deductionMinutes`는 사용자가 넣은 입력값이다(파생값 아님). "남은 시간 공제하고 퇴근"(§5)은 퇴근 순간 계산한 값을
  입력값으로 저장한다 — 이후 출근 시각을 고쳐도 공제는 따라 바뀌지 않는다. 시트에서 직접 고친다.

### Drift v1 → v2

- `work_records`에 `deduction_minutes INTEGER NOT NULL DEFAULT 0`, `deduction_reason TEXT NULL` 추가.
- `type`은 textEnum(이름 저장)이라 `businessTrip` 추가에 마이그레이션 불필요.
- `schemaVersion = 2`, `onUpgrade`에서 `from1To2` 두 컬럼 addColumn. `drift_schemas/drift_schema_v2.json` 덤프,
  v1→v2 마이그레이션 테스트(기존 행 보존 · 공제 0 · 사유 null).

### WorkRules

```dart
this.businessTripCreditMinutes = 480,  // 8h
this.deductionStepMinutes      = 10,   // 시간공제 휠 분 단위
```

시간공제 상한은 규칙 값이 아니라 **그날 기본 기준시간**(일반 8h · 반차 4h)이다.

## 2. 계산 규칙

### 그날 기준시간

| 유형 | 기본 기준 | 시간공제 | 그날 기준시간 |
|---|---|---|---|
| 일반 | 8h | 가능 | 8h − 공제 |
| 반차 | 4h | 가능 | 4h − 공제 |
| 연차 | 0 | — | 0 |
| 공휴일 | 0 | — | 0 |
| 출장 | 0 (8h 인정) | — | 0 |

```
주간 목표 = 40h − Σ(8h − 그날 기준시간)   (평일만, 기록 없는 평일은 8h)
         = 40h − 반차×4h − (연차+공휴일+출장)×8h − Σ시간공제
```

### 하루 실근무

```
일반        = 퇴근 − 출근 − 60분
반차        = 퇴근 − 출근
주말        = 퇴근 − 출근
공휴일 근무  = 퇴근 − 출근           (점심 공제 없음, 시각이 없으면 0)
연차·출장    = 0
```

- 점심 공제 조건: **반차가 아니고, 주말이 아니고, 공휴일이 아닐 것.**
- 시간공제는 실근무에 영향이 없다. 점심 공제도 평소대로 — 기준에서만 뺀다.

### 주간 실적

```
주간 실적 = 평일 실근무 합계 — 단, 공휴일 근무는 넣지 않는다
```

- **공휴일 근무 = 주말 근무와 같은 취급.** 목표에서 8h는 그대로 빠지고, 일한 시간은 실적에 안 들어간다.
  그날 근무시간만 보이고 기준 대비 ±는 없다. 기록 누락으로 잡지 않는다.
- 주간 탭의 "주 40시간 제외" 합계(`weekendMinutes`)에 공휴일 근무도 더한다 → `excludedMinutes`로 이름을 바꾼다.

### 기준 대비 (deltaMinutes)

`실근무 − 그날 기준시간`. 주말·공휴일은 null. 시간공제 2h인 일반일에 5h 일했으면 5h − 6h = −1h.

### 근무일 (남은 평일 · 첫/마지막 근무일)

쉬는 날 = 연차 · 공휴일 · **출장**. 공휴일에 일했어도 근무일로 세지 않는다.
시간공제가 8h 전부인 일반일은 근무일로 센다(단순하게 — 유형으로만 판정).

### 오늘 몫

```
공제 반영 전 몫 = (이번 주 남은 시간 + 오늘 포함 남은 근무일들의 시간공제 합) ÷ 남은 근무일 수
오늘 몫        = 공제 반영 전 몫 − 오늘 시간공제
반차인 날      = 4h − 오늘 시간공제 (고정)
```

- 공제는 **그날에만** 반영된다. "오늘 2h 일찍" 공문이 남은 날에 30분씩 흩어지지 않게.
- 안내 문구의 기준선도 8h가 아니라 **그날 기준시간(8h − 공제) ±30분**.
- 퇴근 예상은 여전히 화면에 쓰지 않는다.

### 기록 누락

- 대상 = 평일 중 **그날 기준시간 > 0**인데 출퇴근이 하나라도 빈 날 (기록 없는 평일 포함).
- 공휴일·연차·출장, 그리고 공제로 기준이 0이 된 날은 누락이 아니다.

## 3. 오늘 화면

### 출근 전 보조 슬롯

`○ 오늘은 연차 · ○ 오늘은 공휴일 · ○ 오늘은 출장` (라디오 3개). 320 폭에서 넘치면 라벨을 "연차 / 공휴일 / 출장"으로
줄인다(측정 후 결정). 시간공제는 이 슬롯에 넣지 않는다 — 미리 알면 주간·월간 시트, 당일이면 §5.

### 출장 상태

연차/공휴일 상태와 같은 골격. 배지 "출장", 상태 블록 "오늘은 출장입니다 / 8시간 근무로 인정돼요", 주 버튼 비활성,
보조 슬롯 "되돌리기".

### 공휴일 상태 → 공휴일 근무

- 공휴일 상태에서 **주 버튼 "출근하기"를 활성화**한다. 누르면 유형은 공휴일 그대로 출근 시각만 찍는다.
  (연차·출장은 지금처럼 비활성. 연차인데 일하게 되면 되돌리기 후 출근.)
- 근무 중: 상태 블록은 평소와 같다(점심 미공제로 경과). 보조 슬롯은 주말과 같이 **반차 체크 없이** "출근 변경 · 출근 취소".
  §5 체크박스도 없다(기준이 없으므로).
- 출근 취소: 기록을 지우지 않고 **시각만 비우고 공휴일은 유지**한다.
- 퇴근 완료: 요약 4칸 중 기준 대비는 "—".

## 4. 시간 수정 시트

### 유형 선택지

반차 · 연차 · 공휴일 · **출장** (4개). 과거는 칩 4열, 미래는 전체 너비 행 4개. 출장 색 토큰 신설
(`tripBackground` / `tripText`, 기존 유형들과 같은 채도의 청회색 계열).

- 연차·출장 칩: 지금의 연차처럼 **누르는 순간 저장·닫기.** 시각이 있던 날이면 한 번 확인.
- **공휴일 칩: 반차처럼 초안만 바꾼다.** 시각 행이 남아 있고(비워도 됨), 저장 버튼으로 마무리.
  공휴일을 고르면 주말처럼 안내 줄 "공휴일 근무는 주 40시간에 포함되지 않아요"가 뜬다.
  계산 내역은 주말과 같이 근무 · 점심 공제("없음 (공휴일)") 두 줄.
- 미래 날짜는 지금처럼 어느 유형이든 누르면 즉시 저장.

### 시간공제 행

- 노출 조건: 평일 && 초안 유형이 일반 또는 반차. 과거·오늘·미래 모두.
- 위치: 과거 시트는 출·퇴근 행 아래, 미래 시트는 유형 행 아래. 모양은 출·퇴근 행(`TimeRow`)과 같다.
  라벨 "시간공제", 값은 0이면 "없음", 있으면 "2시간 30분".
- 행을 누르면 휠 박스가 펼쳐진다(출·퇴근 휠과 동시에 하나만 펼친다):
  - 제목 "뺄 시간"
  - 휠 두 열: **시간 0–8 · 분 00–50 (10분 단위)**. 입력 단위 표시 "시간" / "분".
  - 휠 박스 아래 사유 입력칸(한 줄, 선택, 최대 20자, 힌트 "사유 (선택) 예: 조기퇴근 공문")
  - 그 아래 설명 한 줄: "연차·반차로 안 되는 시간을 직접 넣어 이 날 기준시간에서 빼요"
- 공제가 0이 아닐 때만 사유가 저장된다. 공제를 0으로 돌리면 사유도 지워진다.
- 상한: 반차인 날 4h를 넘으면 저장 비활성 + "반차인 날은 4시간까지 뺄 수 있어요" (휠 자체는 0–8 그대로).
- 계산 내역: 근무 / 점심 공제 / **시간공제 −2h 30m** (0이면 줄 생략) / 기준(공제 반영값) / 기준 대비.
- 휠 단위와 맞지 않는 값(§5에서 저장된 2h 47m 등): 행은 정확한 값을 보여주고, 휠은 10분 단위로 내림한 위치에서
  열린다. 휠을 돌리기 전까지 값은 바뀌지 않는다.

### 미래 시트의 저장 버튼

미래 시트는 저장 버튼이 없지만, **시간공제 행을 펼치면 저장 버튼이 나타난다.** 유형 행 탭은 지금처럼 즉시 저장·닫기.

### 키보드 · 포커스

- 사유 칸 포커스 시 시트가 키보드 위로 올라온다(`viewInsets.bottom` 반영) — 입력칸과 저장 버튼이 가려지지 않게.
- 키보드 완료 키(`TextInputAction.done`) → 포커스 해제.
- 입력칸 밖(시트 빈 곳·다른 행·휠)을 누르면 포커스 해제. 휠을 돌리는 순간에도 해제.
- 저장·닫기 시 포커스 해제 후 닫는다(키보드 잔상 없이).
- 휠 박스를 접으면 사유 칸도 함께 접히지만, 입력한 사유는 초안에 남는다.

### 오늘 편집 잠금 (isTodayInProgress 변경)

| 오늘 상태 | 주간·월간에서 탭 |
|---|---|
| 출근 전 (기록 없음 · 유형만 · 공제만) | **미래 날짜와 같은 시트** — 유형 + 시간공제, 시각 없음 |
| 근무 중 | 잠금 · 토스트 "오늘 기록은 퇴근한 뒤에 수정할 수 있어요" |
| 퇴근 완료 | 다른 날처럼 전체 시트 |

→ `isTodayInProgress`를 `isTodayWorking`(오늘 && 출근 있음 && 퇴근 없음)으로 좁힌다.
연차·공휴일 오늘의 "오늘 탭에서 되돌릴 수 있어요" 토스트는 없어진다(시트에서 바로 바꿀 수 있으므로).

## 5. "남은 시간 공제하고 퇴근" (당일 공문)

근무 중 상태 블록(높이 104 고정) 셋째 줄에 사각 체크박스 **"남은 시간 공제하고 퇴근"**.

```
        09:12 출근
     5시간 48분째 근무중
   ☐ 남은 시간 공제하고 퇴근
 [        퇴근하기        ]
 ☐ 오늘 반차 · 출근 변경 · 출근 취소
```

- 노출: 평일 && 공휴일이 아닌 근무 중. 주말·공휴일 근무엔 없다.
- 체크하면 주 버튼 문구가 **"공제하고 퇴근하기"**로 바뀐다.
- 퇴근 시: `deductionMinutes = max(0, 그날 기본 기준 − 실근무)` (일반 8h / 반차 4h, 실근무는 퇴근 시각 기준, 분 단위 그대로).
  기존 공제가 있었어도 이 값으로 덮는다. 사유는 건드리지 않는다.
  예) 09:00 출근 · 15:00 퇴근 · 일반 → 실근무 5h → 공제 3h → 기준 대비 ±0.
- 이미 기본 기준 이상 일했으면 공제 0 (그냥 퇴근과 같다).
- 체크 상태는 저장하지 않는 화면 상태다. 퇴근·출근 취소·앱 재시작 시 꺼진다.
- 퇴근 취소를 해도 저장된 공제는 남는다(시트에서 지운다).

## 6. 주간 · 월간

### 주간

- 첫 카드 요약 줄: `연차 1 · 반차 1 · 공휴일 1 · 출장 1 · 공제 2h 30m` (0 생략, 전부 없으면 줄 생략).
- 행 배지: 출장 배지 추가. 시간공제가 있으면 **"공제 2h 30m" 배지**(중립색 토큰 `deductionBackground`/`deductionText`).
  반차 + 공제면 배지 둘.
- 행 메모: 사유가 있으면 기존 메모 뒤에 `· 사유`, 한 줄 말줄임. 예) `09:00–15:00 · 조기퇴근 공문`
- 공휴일 근무 행: 값 = 근무시간, 배지 "공휴일", 메모 `주 40시간 제외 · 10:00–15:00`, 우측 ± 칸 비움 (주말 근무와 같음).
- 행 높이 7행 동일 테스트 유지 (배지 둘·긴 사유 케이스 추가).

### 월간

- 범례에 출장 추가 (반차 · 연차 · 공휴일 · 출장). 320 폭에서 한 줄에 들어가는지 확인.
- 출장 날은 출장 색 원.
- 공휴일 근무 날: 공휴일 색 원 + 값은 주말 근무처럼 부호 없는 근무시간.
- **시간공제는 캘린더에 표시하지 않는다.** 셀 값(기준 대비)에만 반영된다.

## 7. 테스트 (먼저 쓴다)

- 공휴일 근무: 점심 미공제, 주간 실적 제외, delta null, 누락 아님, excludedMinutes 포함
- 출장: 목표 −8h, 근무일 제외, 첫/마지막 근무일 판정, 누락 아님
- 시간공제: 목표 반영(일반·반차), 미래 공제 즉시 반영, delta, 오늘 몫(그날에만 반영), 안내 기준선, 공제로 기준 0 → 누락 아님
- 유형 전환 시 공제·사유 정리, 공제 0이면 사유 null
- 반차 공제 상한 검증
- "남은 시간 공제하고 퇴근" 계산 (일반·반차·이미 초과)
- 공휴일 출근/출근 취소가 유형을 유지
- `isTodayWorking` 잠금 범위
