# 시간 출장 (초안, 2026-11-10)

> **상태: 초안.** 논의 내용 정리만 한 것. 구현 전 열린 질문(§7)을 확정한다.

## 0. 왜

- 요청: "출장 시간을 입력할 수 있으면 좋겠다 (ex 3시간 출장, 나머진 정상 근무)".
- 지금 출장은 하루 단위 유형(`businessTrip`, `isOffType`) — 고르면 그날 기준 0h, 출퇴근 시각이 지워진다.
  "오전 출장 → 13시 사무실 출근 → 남은 시간 채우기"를 표현할 수 없다.
- 시간공제로 계산은 흉내 낼 수 있지만, 사용자는 "출장"을 찾지 "시간공제"를 떠올리지 않고,
  기록에도 출장이라는 사실이 남지 않는다. **출장이라고 기록이 남아야 한다.**

## 1. 개념

- **종일 출장**: 지금 그대로. 유형 `businessTrip`, 쉬는 날, 시각 없음. 여러 날 출장도 지금처럼 날마다 칩 한 번.
- **시간 출장**: 쉬는 날이 아니다. 출퇴근이 필요하고 근무일로 세며 기록 누락 대상이다.
  **시작·끝 시각 범위로 입력하고, 인정 시간은 범위 통째(끝 − 시작).** 점심 창과 무관하다.
  - 출장 중 점심은 언제 먹을지 정해져 있지 않다 — 12–13시 창으로 빼는 건 억지다.
  - 예: 출장 09:00–13:00 → 4h 인정. 점심을 먹었으면 사용자가 09:00–12:00으로 넣는다.
  - 범위로 받는 이유: 언제 출장이었는지 기록이 남고, "몇 시부터 몇 시까지"가 기억하기 자연스럽고,
    출퇴근 구간과의 겹침을 막을 수 있고, 규칙이 바뀌어도 시각이 남아 다시 계산할 수 있다.
- 계산상으로는 시간공제와 같은 "그날 기준에서 뺌" 방식 (종일 출장도 목표에서 8h를 빼는 방식이라 일관된다).

```
출장 인정 = tripEnd − tripStart   (없으면 0)
그날 기준 = 기본(일반 8h · 반차 4h · 쉬는 날 0) − 시간공제 − 출장 인정   (0 미만 없음)
```

- 오늘 몫: 공제와 같이 **그날에만 반영** (남은 날들의 출장 인정분을 되돌려 균등 배분 후 오늘 것만 뺀다).
- **하루 출장 범위는 하나.** 오전·오후 둘 다 출장인 날은 처음부터 일정 끝까지 하나로 본다 — 사실상 종일 출장이다.

## 2. 데이터

- `WorkRecord`에 `tripStart`, `tripEnd` (DateTime?, 둘 다 있거나 둘 다 없음). 시간 출장 날은 `type = normal` 또는 `halfDay`.
  `businessTrip` 유형에 시각을 붙이지 않는다 — `isOffType`을 보는 곳 전부가 흔들린다.
- 인정 시간(분)은 저장하지 않는다 (파생값 미저장 원칙).
- **Drift 스키마 v3** (컬럼 2개) + 마이그레이션 테스트, **백업 format 3** (format 1·2는 그대로 읽힘 — 기존 기록 변환 없음).
- `sanitizeRecord`: 평일 일반·반차에서만 유지, 그 외(쉬는 날·주말·공휴일)는 비운다.

## 3. 검증

- 끝 > 시작, 같은 날 안 (자정 넘김 미지원).
- 출퇴근 구간과 겹치면 안 된다 (겹친 시간이 두 번 세진다).
- 출장 인정 + 시간공제 ≤ 그날 기본 기준 (일반 8h · 반차 4h).
- **반차 + 시간 출장 허용.** 반차가 켜져 있으면 출장은 "시간"만 고를 수 있다 (반차 + 종일 출장은 없다).
  시간 출장이 있는 날 반차를 켜서 출장 인정 + 공제가 4h를 넘으면 안내를 띄우고 저장을 막는다
  (공제의 "반차인 날은 4시간까지"와 같은 방식).

## 4. 입력 흐름

### 시트 (주간·월간·출근 전 오늘)

- 출장 칩/행을 누르면 바로 닫지 않고 아래에 **"종일 / 시간"** 선택이 생긴다.
  - **종일** → 지금처럼 즉시 저장하고 닫힘 (시각이 있던 날이면 지워진다고 확인). 탭 하나만 늘어난다.
  - **시간** → 작은 시트가 겹쳐 뜬다 (공제 시트와 같은 골격, 큰 시트 안에 휠을 펼치지 않는다 — 2026-09-27 넘침 이력).
    시작·끝 휠(오전/오후 · 시 · 분, 출퇴근 휠 재사용) + 결과 한 줄 "09:00–13:00 · 4h 인정".
- 미래·출근 전 오늘(저장 버튼 없음): 작은 시트의 "저장"으로 바로 저장.
- 과거·퇴근한 오늘: 작은 시트 "확인" → 큰 시트 초안 반영 → 저장 버튼 (반차와 같은 흐름). 출퇴근 시각 유지.
- 출근 전 오늘 라디오(연차·공휴일·출장)에서 출장을 고를 때도 종일/시간을 묻는다.
- 시간 출장이면 오늘 화면에 **출근하기 버튼이 남는다.** 종일이면 지금처럼 없다.

### 오후 출장 — 근무 중 "출장 처리하고 퇴근"

- 출근 후에 출장이 정해지는 경우(오전 사무실 → 오후 출장 → 복귀 안 함). 근무 중엔 시트가 잠겨 있으므로 오늘 화면에서 처리한다.
- 지금 "☐ 남은 시간 공제하고 퇴근"을 확장 — 체크하면 "공제 / 출장" 선택, 주 버튼 "공제하고 퇴근하기" / "출장 처리하고 퇴근하기".
- 저장: 출장 시작 = 퇴근 시각, 끝 = 퇴근 시각 + `max(0, 기본 기준 − 시간공제 − 실근무)`. 점심으로 밀리는 계산 없음.
  예: 9시 출근, 14시 출장 처리 퇴근 → 실근무 4h → 출장 14:00–18:00.
- 실근무가 이미 기준 이상이면 출장 값 없음.
- **이미 출장 범위가 있는 날**(오전 출장 → 사무실 → 오후 또 출장): 범위를 하나로 보므로 확인
  ("오전에도 출장이 있어서 오늘은 종일 출장으로 바뀌어요") 후 **종일 출장으로 저장** — 출퇴근 시각은 지워지고 8h 인정.
- 레이아웃 테스트 "주 버튼 Y는 이 줄만큼만 아래"의 기준이 바뀔 수 있다.

## 5. 표시

- 주간 행 배지 "출장 4h" (인정 시간). 시트에서 시각 범위.
- 주간 요약 줄 "출장 n" — 종일·시간 출장을 어떻게 셀지 §7.
- 월간 캘린더 원 색 — §7.
- 오늘 화면 시간 출장 날 상태 블록 표시 문구 — 디자인에서.

## 7. 열린 질문

1. 휠 기본값 (예: 09:00–12:00?)
2. 주간 요약 "출장 n" — 시간 출장도 1로 세는가, 시간으로 따로 쓰는가
3. 월간 캘린더에서 시간 출장 날 원 색 (출장색 / 일반 근무색)
4. 근무 중 체크 줄 UI — 체크 후 세그먼트 vs 한 줄 "남은 시간 [공제|출장] 처리하고 퇴근"
5. 여러 날 기간 입력은 범위 밖 (연차·출장 공통 문제, 요청 생기면 별도)
