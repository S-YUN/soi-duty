# Handoff 3: SOI DUTY — 스플래시 & 앱 아이콘

`README.md`(오늘 화면)의 토큰·폰트 규칙을 그대로 따른다. 이 문서는 앱 첫 진입 화면과 아이콘만 다룬다.

---

## 1. 스플래시 화면

### 레이아웃
- 화면 전체 배경 **`#1B473A`** (브랜드 딥그린). 상태바 아이콘은 밝은 색(light content).
- 로고를 **화면 정중앙**에 배치. `logo-transparent.png`, **폭 252**, 높이는 비율 유지.
- 하단 로딩 영역: 화면 **바닥에서 64** 띄우고 가로 전체 가운데 정렬, 세로 `Column` gap 14
  - 진행 바 트랙: **96×4**, radius 999, `rgba(244,246,243,.2)`
  - 진행 바 채움: 높이 100%, radius 999, **`#9FD3B4`** (민트 액센트)
  - 문구: "근무 기록 불러오는 중", **11.5px / letter-spacing 0.06em / `#C9D8CE`**

### 애니메이션
- **로고 등장**: `opacity 0 → 1`, `scale .94 → 1`, **0.5s `cubic-bezier(.22, .8, .3, 1)`**, 화면 진입 즉시 1회.
- **진행 바**: 폭 `0 → 100%`를 **1.6s `ease-in-out`, 무한 왕복(alternate)**. 실제 로딩 진행률이 아니라 대기 표시다 — 데이터 준비가 끝나면 즉시 다음 화면으로 전환.
- 전환: 스플래시 → 오늘 화면은 페이드(0.2s 내외). 최소 노출 시간을 인위적으로 두지 않는다. 준비되면 바로 넘어간다.

### 구현 메모
- Flutter에서는 native splash(`flutter_native_splash`)와 첫 프레임 사이가 이어져 보이게, native splash도 배경 `#1B473A` + 같은 로고로 설정하는 것이 좋다. 그러면 이 화면은 실질적으로 native splash의 연장이 된다.
- 로딩이 200ms 안에 끝나면 진행 바가 번쩍이는 것처럼 보인다. 그 경우 진행 바·문구를 생략하고 로고만 보여도 된다.

## 2. 앱 아이콘

로고는 **투명 PNG로만 관리**한다. 배경색이 필요한 곳은 앱에서 배경을 채우고 그 위에 투명 로고를 얹는다 — 배경이 구워진 이미지는 쓰지 않는다.

### 생성 방법
- 정사각형 캔버스를 **`#1B473A`**로 채우고, `logo-transparent.png`(마크 + SOI DUTY 워드마크)를 **78% 크기로 중앙 배치**
- `flutter_launcher_icons` 설정:
  - `adaptive_icon_background: "#1B473A"`
  - `adaptive_icon_foreground`: 투명 로고 (Android adaptive icon의 safe zone을 고려해 여백을 넉넉히)
  - iOS는 알파를 허용하지 않으므로 배경이 합성된 1024×1024 PNG가 필요하다 — 위 방식으로 생성
- radius는 OS가 마스킹한다. 이미지에 직접 둥근 모서리를 굽지 않는다.

### 사이즈별 주의
- 120px, 60px: 로고 전체(워드마크 포함)로 충분히 읽힌다
- **36px 이하**: 마크 안의 "12h / 40h" 글자와 SOI DUTY 워드마크가 모두 뭉개진다 → 워드마크를 뺀 `mark-transparent.png`를 쓰거나, 마크를 더 단순화한 별도 버전이 필요하다
- 벡터(SVG/PDF) 원본이 있으면 작은 사이즈에서 훨씬 선명하다. 현재는 PNG만 있다.
