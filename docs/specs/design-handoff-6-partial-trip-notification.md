# 1부. 시간 출장

## 0. 브리프 대비 바뀐 점

브리프 6 1부는 "출장 표시(켜기/끄기)"였다. 최종은 아래로 확정했다.

- 기록하는 것은 출장 여부가 아니라 **출장 시작·끝 시각 범위**. 하루에 하나.
- **계산에 전혀 영향이 없다.** 시간 출장 날은 일반 근무일(반차면 반차)이고, 잔여·기준 대비·알림은 출퇴근으로만 계산한다. 출장 출발 때 출근, 일이 끝날 때 퇴근을 찍는다.
- 출장 칩(행)을 누르면 **"종일 출장 / 시간 출장"** 을 고른다. 종일 출장은 지금 그대로.

## 1. 데이터

```dart
@freezed
class WorkRecord with _$WorkRecord {
  const factory WorkRecord({
    required DateTime date,
    DateTime? clockIn,
    DateTime? clockOut,
    @Default(WorkType.normal) WorkType type,
    @Default(0) int deductionMinutes,
    DateTime? tripStart,   // 시간 출장 — 둘 다 있거나 둘 다 없다
    DateTime? tripEnd,
  }) = _WorkRecord;
}
```

- 붙을 수 있는 날: 일반 · 반차 · 공휴일(근무) · 주말 · 미래 날짜. **연차·종일 출장으로 바꾸면 비운다** (`sanitizeRecord`).
- 유효성: `tripEnd > tripStart` 하나뿐. 출퇴근 구간과 겹쳐도 되고, 근무 중에 아직 안 온 끝 시각도 된다. 자정 넘김 없음(그날 안).
- 계산 함수는 이 두 값을 읽지 않는다. 파생값(길이)은 표시할 때만 `tripEnd − tripStart`.
- **Drift 스키마 v3** (컬럼 2개) — CLAUDE.md의 절차대로 `schemaVersion` 올리고 덤프·검증·마이그레이션 테스트(v2 데이터 보존).
- **백업 format 3**: `records[]`에 두 필드 추가. format 1·2 파일은 없는 것으로 읽는다.
- 저장 결과가 "시각 없음 · 공제 0 · 출장 범위 없음"인 `normal`이면 지금처럼 행을 지운다. **출장 범위만 있는 미래 날짜는 남긴다.**
- 주간 요약 "출장 n"은 **종일 출장 + 시간 출장 날을 모두 1**로 센다.

## 2. 시트 — 출장 고르기

출장 칩(과거·퇴근한 오늘) / 출장 행(미래·출근 전 오늘)을 누르면 즉시 저장하지 않고 **아래에 선택 패널이 열린다.** 다시 누르면 닫힌다.

| 요소 | 값 |
|---|---|
| 패널 | 배경 `#F1F3EE`, 라운드 14, 패딩 12, 위 여백 8. 과거 시트는 칩 그리드 바로 아래, 미래 시트는 유형 행 4개 바로 아래 |
| 안내 | "출장을 어떻게 넣을까요?" 13 · subtle, 아래 9 |
| 버튼 2개 | 가로 나란히 gap 8, 각 배경 `#FCFCFB` · 라운드 12 · 최소 높이 58 · 패딩 10/12 |
| 버튼 제목 | 15 / w600 · ink. 현재 선택된 쪽은 브랜드색 + 제목 뒤 " ✓" + 안쪽 1.5 브랜드 테두리 |
| 버튼 보조 | 12.5 · subtle · **한 줄 고정(줄바꿈 없음)** |
| 해제 | 출장(종일이든 시간이든)이 있으면 패널 아래 가운데 "출장 빼기" (13.5 · subtle, 히트 44) |

| 버튼 | 제목 | 보조 | 누르면 |
|---|---|---|---|
| 종일 | 종일 출장 | 8시간 인정 | 지금의 출장 칩과 같다 — 즉시 저장하고 닫힘. 시각이 있던 날은 기존 "출장으로 바꿀까요? / 입력한 출퇴근 시각이 지워져요" 확인 |
| 종일 (반차 켠 날) | 종일 출장 (`#C3C7BE`) | 반차인 날은 안 돼요 | 아무 일 없음 |
| 시간 | 시간 출장 | 시간 직접 입력 · (넣은 뒤엔) `09:20–12:30` | 시간 출장 작은 시트(§3) |

- 공휴일 날 시간 출장을 고르면 **유형은 공휴일 그대로**, 범위만 붙는다. 연차·종일 출장 날에 고르면 유형이 풀린다(일반).

### 2-1. 선택된 모습

- **칩**: 시간 출장도 반차·연차·공휴일처럼 출장색으로 채우고 ✓ (`#D3DDE3` / `#3F5866`). 종일과 같은 모양이다 — 구분은 시트 구성이 한다(종일은 출퇴근 행이 없고, 시간 출장은 출퇴근 행 + 출장 행).
- **미래 시트 출장 행**: 선택 배경 `#DDE8E1` + ✓, 라벨 "출장" 옆에 범위 `09:00–12:00` (13 / w500 / `#3F5866`, gap 8).
- **과거·퇴근한 오늘 시트 "출장" 행**: 출퇴근 행(과 휠) 아래, 시간공제 행 위. 시간공제 행과 같은 골격 — 라벨 "출장" 13 subtle / 값 `09:20–12:30` 20 · w500. 누르면 §3 작은 시트(확인 + 출장 지우기).
- **주말 시트**: 칩이 없으므로 "출장" 행을 늘 보인다. 값은 없으면 **"없음"**, 누르면 §3.
- **계산 내역에는 아무 줄도 넣지 않는다.**

## 3. 시간 출장 작은 시트

시간공제 작은 시트와 같은 겹침 구조(큰 시트 위, 휠을 큰 시트 안에 펼치지 않는다).

| 요소 | 값 |
|---|---|
| 제목 | 시간 출장 (16 / w600) |
| 설명 | 몇 시부터 몇 시까지 출장이었는지 기록으로 남겨요. (13 · subtle, 위 6) |
| 시작·끝 칸 | 가로 2칸 + 사이 "–"(18 · `#9DA296`), 위 12. 각 칸: 라벨 "시작"/"끝" 13 subtle, 값 20. **고른 칸** = 값 w600 브랜드 + 아래 2px 브랜드, 다른 칸 = w500 ink + 아래 1px `#E7E9E3`. 칸을 누르면 휠이 그 값을 고친다. 처음엔 "시작" |
| 휠 | 출퇴근 휠 그대로(오전/오후 · 시 1–12 · 분), 박스 `#F1F3EE` 라운드 14 패딩 16/14, 높이 176, 위 14 |
| 결과 줄 | `09:00–12:00 · 3시간` (14.5 / w500 ink, 가운데, 위 14) — 길이는 `formatKoreanDuration` |
| 안내 (끝 ≤ 시작) | 결과 줄 자리에 **"끝이 시작보다 늦어야 해요"** (13.5 / w500 minus), 버튼 비활성(`#EDEFEA` · subtle) |
| 버튼 | 52 · 라운드 13, 위 12. **"확인"** = 과거·퇴근한 오늘(큰 시트 초안에 반영, 큰 시트 저장으로 마무리) / **"저장"** = 미래·출근 전 오늘·오늘 화면(바로 저장하고 다 닫힘) |
| 지우기 | 이미 있는 범위를 고칠 때만 "출장 지우기" (13.5 subtle, 히트 44) |
| 작은 기기 | 시트 최대 높이 = 화면 − 44, 넘치면 시트 안 스크롤 (SE 320×568) |

**처음 값**: 시작 = 그날 출근 시각(오늘 화면 근무 중이면 출근 시각, 과거 시트는 출근 행 값), 없으면 09:00. 끝 = 시작 + 3시간(23:59에서 멈춤). "출근 = 출장 출발"이 흔한 경우에 맞춘 값이다. `WorkRules`에 기본 길이(180분)·기본 시작(540분)을 둔다.

## 4. 오늘 화면

근무 중엔 주간·월간 시트가 잠겨 있으므로 오늘 화면에 길이 필요하다. **보조 슬롯과 "남은 시간 공제하고 퇴근" 줄은 건드리지 않는다.** 상태 블록 높이도 그대로.

### 출장 칩 (공통)

| 상태 | 모양 |
|---|---|
| 없음 | 투명 배경, 1px **점선** `#C3D0D8`, 12.5 / w600 subtle, 글자 "+ 출장" |
| 있음 | 배경·테두리 `#D3DDE3`, 글자 `#3F5866` 12.5 / w600, "출장 09:12–12:12" |

패딩 3/8, 라운드 6, nowrap. 히트 영역은 바깥 패딩 8/6(음수 마진으로 레이아웃 영향 없이)으로 44에 가깝게. 접근성 라벨: "출장 시간 남기기" / "출장 시간 고치기".

- **출근 전**: 보조 슬롯 라디오 "출장"을 누르면 **"오늘 출장"** 작은 시트(아래). 시간 출장을 넣으면 "아직 출근 전" 옆에 있음 칩(누르면 고치기). 안내 문구·출근하기 버튼·라디오는 그대로.
- **근무 중**: "09:12 출근" 줄 오른쪽(gap 7)에 칩. 없음이면 "+ 출장" → §3 작은 시트("저장"), 있음이면 같은 칩으로 고치기·지우기.
- **퇴근 완료**: 요약 4칸 위에 있음 칩(없으면 아무것도 없음). 고치기는 "시간 수정" 시트.

### "오늘 출장" 작은 시트 (출근 전)

제목 "오늘 출장" → 행 2개(gap 8). 행: 최소 높이 64, 패딩 10/16, 라운드 14, 배경 `#F1F3EE`(선택 `#DDE8E1`), 왼쪽 출장색 점 13, 제목 15.5 / w500 ink + 보조 13 subtle.

| 행 | 보조 | 오른쪽 | 누르면 |
|---|---|---|---|
| 종일 출장 | 출근 없이 8시간 근무로 인정돼요 | 선택 시 ✓ | 지금의 "출장" 라디오와 같다(종일 출장 상태) |
| 시간 출장 | 출퇴근은 그대로 찍고, 출장 시간만 남겨요 | 넣었으면 범위(14.5 / w600 브랜드) | §3 작은 시트("저장") |

## 5. 주간

- 첫 줄 배지에 **"출장 3h 10m"** (길이, `formatHm`). 출장색. 순서: 유형 → 출장 → 공제. 공제 배지 문구는 지금 그대로("30m 공제").
- 종일 출장은 지금처럼 "출장"(시간 없음) — 배지만 봐도 구분된다.
- **배지가 셋이면 셋째(공제)는 둘째 줄 맨 앞**으로 내려간다. 둘째 줄 높이 20 안에 맞게 배지 줄높이 16. 둘째 줄은 지금처럼 출퇴근 범위(넘치면 말줄임).
- 범위는 주간에 쓰지 않는다 — 탭하면 시트에서 보인다.
- 레이아웃 테스트: 7행 높이가 모두 같은지(폭 320·360·600)에 "반차 + 출장 + 공제" 행을 추가.

## 6. 월간

- 유형이 없는 근무일에 시간 출장이 있으면 **날짜 원을 출장색**(`#D3DDE3`, 숫자 `#3F5866`).
- **유형이 먼저**: 반차 + 시간 출장 → 반차 원, 공휴일 근무 + 시간 출장 → 공휴일 원.
- **주말 근무 + 시간 출장 → 출장 원 + 숫자 `#3F5866`.** CLAUDE.md "주말 숫자는 원 위에서도 적갈색"의 예외다 — 적갈색 `#9C5F50`은 출장 원 위 대비 3.6:1로 기준(4.5:1) 미달.
- 셀 값은 평소 근무일과 같다. 범위는 캘린더에 쓰지 않는다. 범례 변경 없음.

# 2부. 퇴근 알림

예약 계산·취소 규칙은 `docs/specs/2026-11-10-clock-out-notification.md` §1·§2·§4를 따른다(시간 출장은 예약에 영향 없음). 아래는 그 스펙에서 바뀌거나 정해진 것.

## 7. 정해진 동작

- 하루 최대 하나, 정시에만, 알림에 버튼 없음.
- **마지막 근무일에 주간이 모자라도 "남았어요" 알림은 없다** — 이번 주를 다 채운 시각에 N2 하나만. (스펙 §2의 "부족 문구, 남은 분 포함" 일일 알림은 뺀다.)
- **앱을 보고 있을 때도 OS 배너를 그대로 띄운다** (iOS 포그라운드 표시 옵션 켜기). 앱 안 토스트로 대신하지 않는다.
- 이미 지난 시각(N3)은 바로 보낸다.
- **늦게 오는 알림은 보내지 않는다.** Android 14 이상은 '알람 및 리마인더'(정확한 알람) 권한이 없으면 OS가 최대 1시간 늦추므로, 이 권한이 없으면 알림을 예약하지 않는다. 사용자가 시스템 설정에서 직접 켜야 한다 → §9-1. iOS·Android 13 이하에는 해당 없음.

## 8. 권한 묻기 — 다이얼로그

- **첫 평일 출근 때 한 번.** 주말·공휴일 근무 출근은 건너뛰고 다음 평일 출근 때 묻는다. 신규·기존 사용자 같은 규칙.
- 출근을 먼저 찍고, 그 위에 다이얼로그. 수락 → OS 권한 창. 거절 → P2 토스트. 다시 묻지 않는다.
- 기존 확인 다이얼로그(제목 16 / 설명 14, 버튼 2개)에 **알림 미리보기 카드**를 설명 아래(위 14)에 넣는다:
  배경 `#F0F2ED` 라운드 14 패딩 11/12 · 앱 아이콘 30(라운드 8, `#1B473A` + 투명 로고, 안쪽 여백 11%) · 오른쪽에 "소이듀티"(12 subtle) / 시각 "18:12"(12 subtle, 오른쪽 정렬) · 아래 "퇴근할 시간이에요"(14 / w600 ink). 장식이라 접근성에서 숨김.
- 확인 다이얼로그 공용 위젯에 **취소 버튼 문구 인자**가 필요하다("안 받을래요", "나중에").
- Android 14+에서 '알람 및 리마인더'가 꺼져 있으면 OS 알림 허용 직후 P6 다이얼로그가 이어진다: **P1 → OS 알림 권한 창 → P6.** 창이 세 번이지만 줄이지 않는다 — P1은 OS 창 전에 맥락을 주는 자리, OS 창은 건너뛸 수 없고, 이 권한은 팝업으로 요청할 수 없어 시스템 화면으로 보내기 전에 이유를 말해야 한다. 한 번뿐인 흐름이고 P6 제목("하나만 더")이 이어지는 단계로 읽히게 한다. P1에 Android 전용 설명을 미리 넣지 않는다(P1이 길어지고 플랫폼마다 달라진다).

## 9. 설정 — "알림" 섹션

- 섹션 순서: **캘린더 · 알림 · 연차 · 수당 · 데이터 · 앱 정보** (앱 동작 설정 → 값 입력 → 데이터·정보).
- 행 하나: "퇴근 알림"(15 / w500) + 보조 설명(13, 위 4) — **켜짐일 때는 보조 설명 없이 한 줄**. 섹션 아래 설명 줄은 없다.
- **토글** (앱의 첫 토글): 트랙 51×31 라운드 999, 켜짐 `#2C5A4C` / 꺼짐 `#CFD3CA`, 노브 27 `#FCFCFB` + 그림자 `0 1px 3px rgba(22,25,26,.25)`, 위치 이동 .18s. 행 어디를 눌러도 토글.
- **OS 권한 꺼짐**: 토글 대신 오른쪽 "설정 열기"(15 / w600 브랜드) + 브랜드 꺾쇠, 보조 설명은 minus 색. 누르면 P4 다이얼로그 → "설정 열기"가 OS 앱 설정을 연다.
- 앱 설정은 켰는데 OS가 미정(P1에서 거절해 OS 창이 뜬 적 없음)이면 토글을 켜는 순간 OS 권한 창. 거기서 거절하면 P5 토스트 + 행은 OS 꺼짐 상태.
- 저장: `Settings` 테이블 키(스키마 변경 없음) — 켜짐 여부, 물어봤는지.

### 9-1. '알람 및 리마인더' (Android 14+)

- **언제 묻나**: 알림을 켠 직후(P1 "알림 받기" → OS 알림 허용 뒤, 또는 설정 토글을 켜서 OS 알림이 허용된 뒤), 이 권한이 꺼져 있을 때만 P6 다이얼로그(P4와 같은 부품).
- "설정 열기" → 시스템 '알람 및 리마인더' 화면을 이 앱으로 바로 연다. 켜고 돌아오면 아무것도 띄우지 않는다(둘째 행이 사라지는 것으로 충분).
- "나중에", 또는 켜지 않고 돌아오면 P7 토스트.
- **설정 둘째 행 (P8)**: "퇴근 알림" 토글 행 바로 아래, 같은 카드 안(사이 1px `#E7E9E3`). **앱 토글 켜짐 + OS 알림 허용 + 이 권한만 꺼짐**일 때만 보이고, 켜지면 사라진다.
  모양은 OS 권한 꺼짐 행과 같다 — 라벨 15 / w500, 보조 설명 13 minus, 오른쪽 "설정 열기"(15 / w600 브랜드) + 브랜드 꺾쇠. 누르면 **다이얼로그 없이** 시스템 화면으로 바로 간다(행 이름이 시스템 화면의 스위치 이름과 같아서).
- **토글 행을 바꾸지 않고 둘째 행으로 두는 이유**: 토글은 "알림을 받고 싶다"는 뜻이고 그건 여전히 켜짐이다. 둘째 행으로 두면 사용자가 토글을 끄는 것으로 이 경고도 함께 치울 수 있고(둘째 행은 토글이 켜져 있을 때만), 무엇을 켜야 하는지가 시스템 화면과 같은 이름으로 따로 보인다. OS 알림 자체가 꺼졌을 때는 앱 토글로 바꿀 수 있는 게 없어 토글 대신 "설정 열기" 행이다.

### 9-2. 상태바 알림 아이콘 (Android)

- 파일 `ic_stat_soiduty` — 24dp, 투명 배경 위 흰 단색 실루엣. 로고의 "카드(진행 막대 두 줄) + 원(파이 조각)"을 줄인 모양, 카드와 원 사이 1.55dp.
- 별도 묶음 `soiduty-status-icon.zip`: 벡터 `res/drawable/ic_stat_soiduty.xml`(권장) · PNG 5종(mdpi 24 ~ xxxhdpi 96) · `res/raw/keep.xml`(shrinkResources 대비) · SVG 원본 · README. 벡터와 PNG는 한쪽만 넣는다.
- `AndroidInitializationSettings('ic_stat_soiduty')` — 기본값 `@mipmap/ic_launcher`면 흰 네모로 뜬다.
- 알림 색 `Color(0xFF2C5A4C)` — 알림 창 머리의 아이콘·앱 이름을 브랜드색으로(기기마다 다름).
- iOS는 해당 없음.
