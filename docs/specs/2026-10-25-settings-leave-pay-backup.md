# 설정 · 캘린더 시작 요일 · 잔여 연차 · 주말 수당 · 백업 (2026-10-25)

테스트 사용자 피드백 4건(2026-10-24). 브리프: `docs/specs/design-brief-4-settings-leave-pay.md`.
디자인: 소이듀티 캔버스 "브리프 4 · 제안" 페이지(아트보드 `Brief4-Settings` · `Brief4-Month` · `Brief4-Prototype`, 마크업은 `Main.dc.html`의 `brief4` 분기).
공휴일 자동 가져오기는 **보류** — 이 스펙에 없다.

처음으로 **설정 화면**이 생긴다. 사용자가 넣는 값은 네 개(시작 요일 · 올해 총 연차 · 시급 · 마지막 내보내기 날짜)이고,
연차·수당은 값을 넣으면 켜지고 "사용 안 함으로 되돌리기"로 끄는 **옵트인**이다. 토글은 없다.

---

## 1. 설정 값과 저장

```dart
enum WeekStart { monday, sunday }

@freezed
class AppSettings {
  @Default(WeekStart.monday) WeekStart weekStart;
  @Default({}) Map<int, int> annualLeaveDaysByYear; // 해 → 총 연차(정수 일). 없는 해 = 사용 안 함
  int? hourlyWage;         // 시급 (원). null = 사용 안 함
  DateTime? lastExportDate; // 날짜만. null = 아직 내보낸 적 없음
}
```

- 기존 Drift `Settings`(key/value) 테이블에 키로 저장한다. 스키마 변경 없음(v2 유지).
  키: `week_start`(`monday`|`sunday`) · `annual_leave_days_<year>`(해마다 한 행, 예 `annual_leave_days_2026`) · `hourly_wage` · `last_export_date`(`yyyy-MM-dd`). null은 행 삭제.
- **총 연차는 해마다 따로 저장한다** (2026-10-25). 설정 화면의 "올해 총 연차"는 지금 해의 값만 보여주고 고친다. 해가 바뀌면 그 해 값이 없으므로
  월간 카드가 빈 상태("—" + 유도 줄)로 다시 입력을 유도하고, 지난해 카드는 지난해 값으로 남는다. 설정값 하나였다면 새해에 고친 값이 지난해 카드까지 바꿔 잔여가 틀어진다.
- Repository 포트 `AppSettingsRepository { Stream<AppSettings> watch(); Future<void> save(AppSettings) }`. Drift 구현체.
  첫 기록일(`first_record_date`)은 지금처럼 `WorkRecordRepository`가 관리한다 — 같은 테이블이지만 소유자가 다르다.
- 입력 규칙: 총 연차는 **해마다 1~99 정수**(빈 값·0은 저장 비활성). 시급은 **1~9,999,999 정수**(최대 7자리, 빈 값·0은 저장 비활성 —
  디자인은 빈 값만 막았지만 0원은 의미가 없어 같이 막는다).
- 수당 배율 `WorkRules.extraWorkPayMultiplier = 1.5`. 사용자 설정 아님. 급여 기간은 달력 월.
- 연차 기준 기간은 1월~12월 고정.

## 2. 월간 캘린더 시작 요일

- `calendarDays(month, weekStart)`: 시작 요일이 일요일이면 그 달 1일이 속한 주의 일요일부터, 마지막 날이 속한 주의 토요일까지.
- 요일 헤더는 상수 배열이 아니라 **첫 주 7일의 실제 요일**로 그린다. 토·일 적갈색은 날짜의 `weekday`로 판단한다.
- 바뀌는 것은 월간 캘린더 열 순서뿐이다. 주간 탭, 주 40시간 계산, "n월 n째주"는 월~일 고정.
- 설정 안내 문구: "주간 탭과 주 40시간 계산은 월~일 그대로예요".

## 3. 연차

```
사용(반일 단위) = Σ 연차 기록 × 2 + Σ 반차 기록 × 1   — 그 해 전체, 미리 찍은 미래 날짜 포함
예정(반일 단위) = 그중 날짜가 오늘보다 뒤인 것          — 오늘은 예정이 아니다
잔여(반일 단위) = 그 해 총 연차 × 2 − 사용             — 예정 포함해서 뺀다. 음수면 "초과"
```

- 해 = **보고 있는 달이 속한 해.** 12월→1월로 넘기면 다음 해 카드.
- 표기 `formatLeaveDays(halfDays)`: 반일 단위 15 → "7.5일", 30 → "15일".
- 예정이 0보다 크면 "사용" 칸 값 아래 **"예정 n일 포함"** (12, `subtle`, 위 간격 3). 잔여는 예정을 포함해 계산한다 — 이미 계획한 날은 더 쓸 수 없는 날이다.
- 월간 카드(§6-2)는 `총 연차가 있거나 그 해 사용 > 0`일 때만 보인다.

## 4. 주말·공휴일 수당

```
주말 분   = Σ 그 달 토·일 기록 중 출퇴근 둘 다 있는 날의 실근무 (점심 공제 없음)
공휴일 분 = Σ 그 달 평일 공휴일 기록 중 출퇴근 둘 다 있는 날의 실근무 (점심 공제 없음)
예상 금액 = floor((주말 분 + 공휴일 분) ÷ 60 × 시급 × 1.5)   — 원 단위 정수, 천 단위 콤마
```

- 근무 중(퇴근 안 찍힘)인 오늘은 넣지 않는다. 찍힌 시간만.
- 월간 카드(§6-2)는 `주말 분 + 공휴일 분 > 0`일 때만 보인다. 시급이 없으면 시간만 보이고 유도 줄이 붙는다.
- 이것은 주 단위 리셋과 무관한 월별 합산이다. CLAUDE.md의 "월간 초과/부족 합계 금지"에 해당하지 않는다.

## 5. 백업 (내보내기 · 가져오기)

파일 하나(JSON)에 기록 전체 + 첫 기록일 + 설정값. 서버·계정 없음.

```json
{ "app": "soi_duty", "format": 1, "exportedAt": "2026-10-25T09:12:00",
  "firstRecordDate": "2026-09-14",
  "settings": { "weekStart": "monday", "annualLeaveDaysByYear": { "2026": 15 }, "hourlyWage": 12500 },
  "records": [ { "date": "2026-09-14T00:00:00.000", "clockIn": "2026-09-14T09:00:00.000", "clockOut": null, "type": "normal", "deductionMinutes": 0 } ] }
```

- `records`는 `WorkRecord.toJson` 그대로(local ISO, Z 없음). `settings`에 `lastExportDate`는 넣지 않는다(기기별 값).
- **내보내기**: 임시 폴더에 `soi_duty_backup_yyyy-MM-dd.json`을 쓰고 OS 공유 시트를 연다. 공유 시트가 "닫힘(dismissed)"이 아니면
  `lastExportDate = 오늘`을 저장하고 토스트 "내보낼 파일을 만들었어요".
- **가져오기**: 파일 선택 → 디코드 → 실패면 토스트 "파일을 읽을 수 없어요. 내보낸 파일이 맞는지 확인해 주세요" →
  성공이면 확인 다이얼로그(제목 "기록을 가져올까요?", 본문 "지금 기록 n건이 파일 내용으로 바뀌어요. 되돌릴 수 없어요.", 확인 "가져오기") →
  한 트랜잭션에서 기록 전부 삭제·삽입, 첫 기록일은 파일 값(없으면 기록 중 최소 날짜, 기록도 없으면 삭제), 설정 세 값 덮어쓰기
  (`lastExportDate`는 유지) → 토스트 "기록을 가져왔어요".
- 디코드 실패 조건: JSON 아님 · `app != "soi_duty"` · `format > 1` · `records`가 배열이 아님 · 레코드 파싱 실패.
- 설정 "데이터" 아래 줄: "아직 내보낸 적 없어요" / "마지막 내보내기 2026년 10월 24일" (연도 포함, 2026-10-25).

## 6. 화면

토큰은 전부 `ui/`에 추가한다. 아래 수치는 디자인 마크업에서 뽑은 값(비율 적용 전 기준 폭 402).

### 6-1. 진입점과 설정 화면

- **톱니**: 알약 탭 줄 오른쪽, 오른쪽 여백 10, 44×44 원형 히트 영역(눌림 배경 `tabContainer`), 아이콘 22 선 1.8 `subtle`. 세 탭 모두에서 보인다.
  알약 위치는 그대로(톱니는 Stack 위에 얹는다).
- **설정 화면**: 전체 화면, 오른쪽에서 밀려오는 전환(260ms, `AppCurves.sheet`), 왼쪽 위 뒤로가기(왼쪽 8, 44×44, 화살표 12×20 선 2 `ink`),
  제목 "설정" 22/600/-0.03em 가운데, 헤더 높이 44. 시스템 뒤로가기도 닫는다. `go_router` 최상위 `/settings`, `context.push`.
- 본문 패딩 18 16 54(+하단 SafeArea). 섹션 라벨 13/500 `subtle` 패딩 0 4 8, 섹션 간격 22. 카드는 기존 `AppDecorations.card`, 패딩 세로 4 가로 20.
  행: 최소 높이 44, 세로 패딩 14(세그먼트 행은 12), 요소 간격 12, 라벨 15/500 `ink`, 보조 설명 13 lh1.45 `subtle` 위 간격 4,
  오른쪽 값 15 `subtle`("사용 안 함") 또는 15/600 `brand`("15일" · "12,500원"), 꺾쇠 8×14 선 1.8 `wheelUnselected`. 행 사이 1px `rowDivider`.
  카드 아래 안내 줄: 위 8, 가로 패딩 4, 13 lh1.5 `subtle`.
- 섹션과 문구:
  - 캘린더 — "시작 요일" 세그먼트 [월 | 일]: 컨테이너 `tabContainer` 패딩 3 간격 2, 항목 패딩 6 16 radius 999, 13, 선택 = `brand` 배경 + `onBrand` 600, 비선택 = 투명 + `subtle` 500.
    안내 "주간 탭과 주 40시간 계산은 월~일 그대로예요".
  - 연차 — "올해 총 연차", 비어 있을 때 보조 "알려주시면 월간 탭에서 남은 연차를 볼 수 있어요". 탭 → 숫자 시트.
  - 수당 — "시급", 비어 있을 때 보조 "알려주시면 주말·공휴일 근무 예상 금액을 볼 수 있어요". 안내 "주말·공휴일 근무 × 1.5배로 계산해요". 탭 → 숫자 시트.
  - 데이터 — "내보내기 / 기록과 설정을 파일 하나로 저장해요", "가져오기 / 파일의 기록으로 지금 기록을 바꿔요". 안내 = 마지막 내보내기 줄(§5).
  - 앱 정보 — "버전" 오른쪽 값 15 `subtle`(`package_info_plus`), "개인정보 처리방침" 외부 링크 아이콘 16 선 2 → `https://s-yun.github.io/soi-duty/privacy.html`.

### 6-2. 숫자 입력 시트 (총 연차 · 시급 공용)

- 바텀시트: 기존 시트 radius 24·그림자·핸들. 패딩 10 20 14. 제목 16/600 ("올해 총 연차" / "시급").
- 입력줄: 위 14, 패딩 8 2 10, 밑줄 2px `brand`. 값 28/600/-0.02em `brand`, 비어 있으면 "0"을 `dotInactive`(#C3C7BE)로. 커서 `brand` 2px.
  오른쪽 단위 "일"/"원" 20/500 `subtle`. **OS 숫자 키패드**(앱이 그리지 않음), 시트는 키보드 위에 뜬다.
- 안내: 위 10, 13 lh1.5 `subtle`. 연차 "1월~12월 기준이에요." · 시급은 잠금 아이콘 14 + "이 기기에만 저장돼요. 누구도 해당 내용을 알 수 없어요."
- 저장: 위 18, 높이 52, radius 13, 15/600. 활성 `brand`/`onBrand`, 비활성 `buttonDisabled`/`subtle`. 활성 조건 §1.
- 값이 있을 때만 그 아래 가운데 "사용 안 함으로 되돌리기" 13.5 `subtle`, 최소 높이 44, 눌림 opacity 0.55 → null 저장 후 닫힘.
- 숫자만, 앞자리 0 제거, 자릿수 한도(연차 2 · 시급 7), 시급은 입력 중 천 단위 콤마 실시간.
- 열 때 현재 값으로 채운다. 바깥 탭·내리기는 저장하지 않는다.

### 6-3. 월간 탭 카드

범례 아래, 간격 12. 순서 **수당(그 달) → 연차(그 해)**. 카드 패딩 20(`weekCardPadding`), 제목 16/600/-0.01em `subtle`.

- **수당 카드** "10월 주말·공휴일 근무": 위 12부터 행(간격 8) "주말 7h 30m" · "공휴일 4h" — 0인 쪽은 행 생략. 라벨 13.5 `subtle`, 값 15/500 `ink`.
  구분선 1px `rowDivider` 여백 14 0 10. 시급 있음: "예상 금액" 13.5 `subtle` + 금액 22/600/-0.02em `brand` ("152,250원"), 위 4.
  시급 없음: 유도 줄(최소 높이 44) "시급을 알려주시면 예상 금액을 보여드려요" 14/500 `brand` + 꺾쇠 8×14 `brand` → 시급 시트.
- **연차 카드** "2026년 연차": 위 12, 3칸(`SummaryRow` 모양 — 라벨 13 `subtle`, 값 18/600, 칸 사이 1px `divider`, 칸 패딩 6 4 2):
  총 연차 | 사용 | 잔여. 사용 칸은 예정이 있으면 값 아래 "예정 1.5일 포함"(12 `subtle`, 위 3). 총 연차 없음 → 총·잔여 "—" `weekendNone`, 그리고 구분선(여백 14 0 6) + 유도 줄 "올해 연차 개수를 알려주시면 남은 연차를 보여드려요" → 연차 시트(**카드의 해**에 저장).
  잔여 `brand`. 초과면 셋째 칸 라벨 "초과", 값 `minus`.
- 시트에서 저장하면 카드가 그 자리에서 바뀐다(스트림).

## 7. 하지 않는 것

- 공휴일 자동 가져오기(보류). 배율·급여 기간·연차 기준일 설정. 수당 카드 탭 → 날짜 목록. 유도 줄 숨기기(×).
- 클라우드 동기화. 자동 백업 알림.
