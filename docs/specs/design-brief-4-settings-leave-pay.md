# 디자인 브리프 4: SOI DUTY — 설정 · 잔여 연차 · 주말 수당 · 데이터 백업

작성일: 2026-10-24
대상: Claude Design (핸드오프 1~3을 만든 쪽)
선행 핸드오프: `README.md`(오늘 화면 토큰·폰트), Handoff 2(주간·월간·시트), Handoff 3(스플래시·아이콘).
토큰·글꼴·간격은 그대로 따른다. 이 문서는 **새로 필요한 화면과 그 이유**만 적는다.

---

## 0. 배경

- 주 40시간 유연근무 기준으로 출퇴근을 찍어 **"이번 주 얼마나 더 채워야 하는지"** 보여주는 앱. 서버 없이 완전 로컬.
- 현재 화면: 하단 알약 탭 3개(**오늘 · 주간 · 월간**, 스와이프 전환). 상단에 날짜 헤더. 모든 내용은 카드.
  월간 탭은 `기간 네비게이터 → 캘린더 카드 → 범례` 세 덩어리뿐이다.
- 지금까지는 **설정 화면이 없다.** 사용자가 입력하는 값은 출퇴근 시각과 근무 유형(반차·연차·공휴일·출장·시간공제)뿐이었다.
- 테스트 사용자 피드백 4건이 모두 "사용자가 값을 하나 넣어두면 앱이 계산해 주는" 기능이라 **설정 화면이 처음 필요해졌다.**
  설정이 들어가면 셸(탭·헤더) 틀이 바뀔 수 있다. 그 판단까지 포함해 부탁한다.

### 들어가는 것 (4건)

| # | 기능 | 사용자가 넣는 값 | 앱이 보여주는 것 | 왜 |
|---|---|---|---|---|
| A | 월간 캘린더 일요일 시작 | 시작 요일 (월/일) | 캘린더 열 순서 | 기본 캘린더 앱이 일요일 시작인 사람에게 월요일 시작이 낯설다 |
| B | 잔여 연차 | 올해 총 연차 일수 (선택) | 올해 사용 n일 · 잔여 n일 | 연차·반차를 이미 찍고 있으니 잔여는 계산으로 나온다 |
| C | 주말·공휴일 수당 | 시급 (선택) | 이번 달 주말·공휴일 근무시간과 예상 금액 | 테스트 회사는 주말·공휴일 근무를 시급 1.5배로 준다. 얼마 받는지 알고 싶어 한다 |
| D | 데이터 백업 | — | 내보내기 · 가져오기 | 폰을 바꿔도 기록을 가져가려고. 서버 없이 파일로 |

### 들어가지 않는 것

- **공휴일 자동 가져오기.** 보류. 설정에 자리를 비워둘 필요 없다.
- 근무 규칙(주 40시간·점심 60분 등)의 사용자 변경. 코드상 준비만 돼 있고 이번엔 노출하지 않는다.
- 로그인·계정·클라우드 동기화.

## 1. 설정 진입점 — 열어둔 결정

두 안 중 하나, 또는 더 나은 안을 제안해 달라. 셸을 바꿔도 된다.

- **(a) 헤더 아이콘.** 오늘·주간·월간 공통 헤더 오른쪽에 톱니. 탭 구조는 그대로. 설정은 자주 들어가지 않으므로 숨겨도 된다는 생각.
- **(b) 네 번째 탭.** 알약 탭에 "설정" 추가. 스와이프 순서의 끝. 지금 알약은 3개 기준 폭이라 다시 잡아야 한다.

고려할 점: B·C의 결과(잔여 연차·예상 금액)를 **어디서 보느냐**가 진입점 결정과 얽힌다. 결과를 월간 탭에 두면 설정은 "값 넣는 곳"이라 (a)로 충분하고,
결과를 설정(또는 새 탭) 안에 두면 자주 들어가게 되니 (b)가 맞다. 이 문서는 **결과는 월간 탭**(3절)을 기본안으로 잡았다.

## 2. 설정 화면

들어갈 정보는 아래 네 묶음. 형태(목록·카드·그룹 나누기)는 맡긴다. 값이 비어 있는 상태(설치 직후)와 채워진 상태 둘 다 필요하다.

### 2-1. 캘린더
- **시작 요일**: 월요일 / 일요일 중 하나.
- 안내 한 줄이 필요할 수 있다: 주간 탭과 주 40시간 계산은 월~일 고정이고, 바뀌는 건 월간 캘린더 모양뿐이다.

### 2-2. 연차
- **올해 총 연차**: 일수. 0.5 단위 허용(반차 단위로 주는 회사가 있다). 비워둘 수 있다.
- 기준 기간은 1월~12월 고정. 입력 없음. (입사일 기준 회사가 나오면 그때 추가)
- 비어 있으면 월간 탭 연차 카드는 "사용 n일"만, 채우면 "잔여 n일"이 붙는다.

### 2-3. 수당
- **시급**: 원 단위 금액. 비워둘 수 있다. 금액은 휠로 고르기엔 자릿수가 많아 숫자 키패드가 될 가능성이 크다 —
  **이 앱에서 키패드가 처음 들어오는 자리**다 (지금까지는 전부 휠·칩·버튼). 어떻게 받을지는 맡긴다.
- 배율은 1.5배 고정. 사용자가 바꾸지 않는다. "주말·공휴일 근무 × 1.5배로 계산해요" 같은 설명 한 줄.
- **"이 기기에만 저장돼요"** 안내 필수. 테스터가 "개발자가 내 시급을 볼 수 있냐"고 실제로 물었다. 위치는 맡긴다.

### 2-4. 데이터
- **내보내기**: 기록 전체 + 설정값을 파일 하나로 → OS 공유 시트(메일·메시지·파일 앱으로 보냄).
- **가져오기**: 파일 선택 → **확인 다이얼로그**("지금 기록 n건이 파일 내용으로 바뀌어요. 되돌릴 수 없어요") → 덮어쓰기.
  확인 다이얼로그는 기존 확인 다이얼로그(16/14, 두 버튼) 재사용 가능.
- 가져오기 성공·실패는 기존 토스트(브랜드색 알약)로.
- 선택: "마지막 내보내기: 10월 24일" 한 줄. 내보내기를 안 해본 사람에게 하라는 신호가 된다.

### 2-5. 앱 정보
- 버전 (예: 1.0.1). 개인정보 처리방침 링크(웹 페이지가 이미 있다). 이 둘이면 충분.

## 3. 월간 탭 — 새로 보여줄 정보 둘

현재 `기간 네비게이터 → 캘린더 카드 → 범례`. 여기에 아래 두 정보가 들어간다. 카드 둘로 나눌지, 하나로 묶을지, 어디에 둘지는 맡긴다.
달을 넘기면 이 정보도 그 달 기준으로 바뀐다.

### 3-1. 연차
- "2026년 연차" — **사용 n일 / 잔여 n일** (총 연차를 안 넣었으면 사용만).
- 사용 = 연차 1 + 반차 0.5. 미리 찍어둔 미래 연차도 사용에 들어간다(이미 그 주 목표에서 빠져 있으니 일관).
- 상태: 잔여가 음수(초과 사용)일 때, 총 연차 미입력일 때, 올해 연차 기록이 하나도 없을 때.
- 연도는 **보고 있는 달이 속한 해**. 12월에서 1월로 넘기면 다음 해.

### 3-2. 수당
- "10월 주말·공휴일 근무" — 주말 n시간 · 공휴일 n시간 → **예상 n원**.
- 시급이 없으면: 아예 숨기거나, "시급을 넣으면 예상 금액을 보여드려요" 식으로 설정 유도. 제안해 달라.
- 주말·공휴일 근무가 0인 달: 숨길지 "0h"로 둘지.
- 금액은 원 단위 정수, 천 단위 구분. 분 단위 근무시간 × 시급 × 1.5를 소수점 버림.
- 선택: 누르면 그 달의 주말·공휴일 근무 날짜 목록(날짜 · 시간). 범위에 넣지 않아도 된다.

## 4. 제약

- 기기 폭 320~600에서 한 줄 값이 잘리지 않을 것. SafeArea 처리.
- 글자 크기는 핸드오프 표보다 키운 현재값 기준: 본문 16 · 안내 15 · 라벨 13 / 값 18 · 배지 12. 가장 작은 글자 11.5(캘린더 값)보다 작게 가지 않는다.
- 색은 기존 토큰 안에서. 연차 보라(`#DFD2DD`/`#5C4459`)·공휴일 적갈(`#E6CFC6`/`#7A4536`)·반차 황토(`#E5DCBB`/`#6A5C2E`)·출장 청회(`#D3DDE3`/`#3F5866`)는
  유형 색이라 카드 안에서 같은 의미로만 쓴다. 금액·잔여 숫자는 브랜드색 `#2C5A4C`, 초과·음수는 `#A8503F`.
- 산출물은 지금까지처럼 `.dc.html` + 토큰 설명. 필요한 상태: 설정 화면 빈 상태/채운 상태, 월간 탭에 새 정보가 들어간 모습, 가져오기 확인.

## 5. 정리 — 정해진 것 / 열어둔 것

| 정해진 것 | 열어둔 것 (디자인에서 제안) |
|---|---|
| 배율 1.5배 고정, 급여 기간 = 달력 월 | 설정 진입점 (헤더 아이콘 vs 네 번째 탭) |
| 연차 기준 1~12월, 총 연차는 선택 입력 | 설정 화면의 형태 전반 |
| 결과는 월간 탭에서 본다 (기본안) | 월간 탭 안에서의 위치·묶음, 시급 없을 때 수당 처리 |
| "이 기기에만 저장" 안내 | 금액을 받는 방식과 입력란 생김새 |
| 가져오기 전 확인 다이얼로그 | "마지막 내보내기" 표시 여부 |
