# 디자인 브리프 5: SOI DUTY — 연차 입력을 "남은 연차 + 기준일"로

작성일: 2026-10-26
대상: Claude Design (핸드오프 1~4를 만든 쪽)
선행 핸드오프: Handoff 4(설정 화면 · 숫자 입력 시트 · 월간 탭 연차 카드). 토큰·글꼴·간격은 그대로 따른다.
이 문서는 **Handoff 4의 연차 부분만** 바꾼다. 수당·백업·캘린더 시작 요일은 손대지 않는다.

---

## 0. 왜 바꾸나

Handoff 4의 연차는 "올해 총 연차"를 정수로 받아 `잔여 = 총 연차 − 앱에 찍힌 연차·반차`로 계산한다. 실사용에서 두 가지가 틀린다.

1. **연중에 설치한 사람은 잔여가 부풀려진다.** 10월에 깔고 총 연차 15를 넣으면, 1~9월에 쓴 연차는 앱에 없으니 잔여가 15일 가까이 나온다.
   설치 전 날짜는 편집도 막혀 있어서 채워 넣을 길도 없다.
2. **0.5일 단위가 안 들어간다.** 회사 시스템은 "잔여 8.5일"처럼 보여주는데 정수만 받는다. (브리프 4에 0.5 허용을 적었지만 구현에서 빠졌다.)

둘 다 입력 개념 하나를 바꿔서 푼다: **"올해 총 연차" → "지금 남은 연차"**.

## 1. 바뀌는 개념 (정해진 것)

```
입력 = 지금 남은 연차(0.5 단위) + 기준일(넣은 날, 앱이 자동 저장)
잔여 = 입력값 − 기준일 이후 날짜에 찍힌 연차·반차 (미리 찍은 미래 날짜 포함)
```

- 회사 시스템이 보여주는 숫자를 **그대로** 옮겨 적는다. 사용자가 뺄셈을 하지 않는다.
- **기준일 = 값을 저장한 날.** 사용자가 고르지 않는다. 기준일 당일에 찍힌 연차는 빼지 않는다(그날 연차는 회사 숫자에 이미 반영된 것으로 본다). 기준일 다음 날부터 뺀다.
- 값을 다시 넣으면 기준일도 그날로 옮겨간다. 회사에서 연차가 추가로 생겼을 때, 숫자가 어긋났을 때 고치는 길이다.
- **1월 1일에 넣으면 총 연차와 같다.** 새해에도 같은 질문 하나면 된다. 해마다 따로 저장하는 규칙은 그대로(설정 행은 지금 해, 월간 카드는 보고 있는 달의 해).
- **0과 0.5가 정상값이다.** "다 썼어요"가 0이고, 그 뒤에 연차를 찍으면 "초과"로 보인다. 끄는 길은 지금처럼 "사용 안 함으로 되돌리기" 하나뿐.
- 단위: 지금은 **0.5 단위**(연차·반차). 나중에 반반차(2시간)가 들어오면 0.25 단위가 된다. 입력 UI는 그때 칸만 늘리면 되는 모양으로 잡아 달라.
- 미리 찍어둔 미래 연차는 회사 숫자에 이미 빠져 있을 수도, 아닐 수도 있다(회사가 승인 시점에 차감하면 빠져 있다). 앱이 알 수 없으므로
  **시트 안내 문구로 "앞으로 쓸 연차(신청해 둔 것 포함)는 아직 남은 것으로 쳐서 넣어주세요"를 알리고**, 이미 미래 연차가 찍혀 있으면
  "이 뒤로 찍어둔 연차 1.5일은 여기서 빼서 보여드려요" 같은 힌트 줄을 시트에 띄운다. 이 두 문구는 다듬어도 된다. 뜻은 유지.

## 2. 설정 화면 — 연차 행

Handoff 4의 연차 섹션 행 하나만 바뀐다. 위치·높이·꺾쇠·구분선은 그대로.

| 상태 | 라벨 | 보조 설명 | 오른쪽 값 |
|---|---|---|---|
| 비어 있음 | 남은 연차 | 알려주시면 월간 탭에서 잔여 연차를 볼 수 있어요 | 사용 안 함 (`subtle`) |
| 채워짐 | 남은 연차 | **10월 26일 기준** (기준일을 사용자가 알아야 다시 넣을 때 헷갈리지 않는다) | 8.5일 (`brand` 600) |

- 보조 설명 자리에 기준일을 넣는 게 맞는지, 값 옆에 작게 붙이는 게 나은지는 제안해 달라. 기준일은 **어딘가에는 반드시 보인다.**
- 섹션 제목 "연차"는 그대로.

## 3. 숫자 입력 시트 — 연차용 변형

Handoff 4의 숫자 입력 시트(총 연차·시급 공용)에서 **연차 쪽만** 아래가 달라진다. 시급 시트는 그대로.

- 제목 "남은 연차".
- 입력줄은 그대로 OS 숫자 키패드 + 정수(0~99, 2자리) + 단위 "일". **빈 값은 "0" 플레이스홀더인데, 이제 0은 저장 가능한 값**이라 "비어 있음"과 "0"을 구분해 보여야 한다. 제안해 달라.
- 입력줄 아래에 **소수 부분 세그먼트 `[ 0 | .5 ]`**. 기본 0. 시작 요일 세그먼트(`tabContainer` 알약)와 같은 생김새면 된다.
  나중에 `[ 0 | .25 | .5 | .75 ]`로 늘어날 수 있으니 4칸이 들어가도 깨지지 않는 폭으로. 세그먼트를 바꾸면 입력줄 값이 "8" → "8.5"로 같이 바뀌거나,
  입력줄은 정수만 두고 세그먼트가 소수를 말하거나 — 어느 쪽이 덜 헷갈리는지 제안해 달라.
- 안내(13 `subtle`), 세 줄 안팎:
  - "회사에서 보여주는 남은 연차를 그대로 넣어주세요."
  - "앞으로 쓸 연차(신청해 둔 것 포함)는 아직 남은 것으로 쳐서 넣어주세요."
  - (미래 연차가 찍혀 있을 때만) "이 뒤로 찍어둔 연차 1.5일은 여기서 빼서 보여드려요." — 조건부 줄이라 **있을 때/없을 때 둘 다** 필요.
- 저장 버튼 활성 조건: **값이 하나라도 입력됐으면 활성**(0 포함). "사용 안 함으로 되돌리기"는 값이 있을 때만, 그대로.
- 시트가 키보드 위에 뜨는 구조라 세그먼트와 안내 줄이 늘어난 만큼 높이가 커진다. 폭 320·높이 작은 기기(iPhone SE)에서 저장 버튼이 키보드에 가려지지 않는지 봐 달라.

## 4. 월간 탭 — 연차 카드

Handoff 4의 3칸 구조(`총 연차 | 사용 | 잔여`)는 유지하되 **칸의 뜻과 라벨**이 바뀐다.

| 칸 | 라벨 | 값 | 비고 |
|---|---|---|---|
| 1 | **10/26 기준** (기준일이 1월 1일이면 "총 연차") | 8.5일 | 사용자가 넣은 값 |
| 2 | 이후 사용 | 1일 | 기준일 다음 날부터 찍힌 연차·반차. 예정이 있으면 아래 "예정 0.5일 포함" 12 `subtle` 그대로 |
| 3 | 잔여 / 초과 | 7.5일 `brand` / 1일 `minus` | 음수면 라벨 "초과" |

- 1칸 라벨에 날짜가 들어가면 길어진다. "10/26 기준"이 13에서 칸 폭(320 기준)에 들어가는지, 안 들어가면 어떻게 줄일지 제안해 달라.
  라벨 대신 카드 제목을 "2026년 연차 · 10월 26일 기준"으로 하고 1칸 라벨은 "남은 연차"로 두는 안도 있다.
- "이후 사용"은 올해 전체 사용이 아니다. 기준일 전에 찍힌 연차는 회사 숫자에 이미 반영됐으니 여기서 세지 않는다. 라벨이 이 뜻을 말해야 한다.
  값을 넣는 순간 2칸이 "올해 사용 1일"(미입력 상태)에서 "이후 사용 0일"로 바뀌므로, 1월 연차가 사라진 게 아니라 뜻이 바뀐 것임을 라벨 차이가 말해야 한다.
- 상태:
  - **미입력**: 1·3칸 "—", 2칸은 라벨 **"올해 사용"**으로 올해 찍힌 연차·반차 합("1.5일" / "0일"), 유도 줄 "지금 남은 연차를 알려주시면 잔여를 보여드려요" → 연차 시트. (Handoff 4와 같은 구조, 문구만.)
  - **기준일 이후 사용 0**: 2칸 "0일"(숫자, "기록 없음"이 아니다).
  - **초과**: 3칸 라벨 "초과", 값 `minus`.
  - **0으로 넣음**: 1칸 "0일", 이후 연차를 찍으면 바로 초과.
- 카드의 해 = 보고 있는 달의 해. 12월에서 1월로 넘기면 새해 카드는 미입력 상태(새해 값이 없으니). 지난해 카드는 지난해 기준일·값 그대로.

## 5. 제약

- 브리프 4 §4 그대로: 폭 320~600, SafeArea, 글자 최소 11.5, 토큰 안의 색. 잔여 `brand` `#2C5A4C`, 초과 `#A8503F`.
- 산출물: `.dc.html` + 토큰 설명. 필요한 상태:
  - 설정 연차 행 빈 상태 / 채운 상태(기준일 보이게)
  - 연차 시트: 빈 값 / "8" + 세그먼트 0 / "8" + 세그먼트 .5 / 0 입력 / 미래 연차 힌트 줄 있는 상태
  - 월간 연차 카드: 미입력 / 정상(예정 포함) / 초과 / 기준일이 1월 1일인 경우

## 6. 정리 — 정해진 것 / 열어둔 것

| 정해진 것 | 열어둔 것 (디자인에서 제안) |
|---|---|
| 입력은 "지금 남은 연차", 기준일은 저장한 날 자동 | 기준일을 설정 행 어디에 보일지 |
| 0.5 단위, 0 허용, 끄기는 "사용 안 함으로 되돌리기" | 세그먼트와 입력줄의 관계 (값이 같이 바뀌는지) |
| 기준일 당일 연차는 빼지 않음, 다음 날부터 | "비어 있음"과 "0"의 구분 |
| 카드 3칸 = 기준 · 이후 사용 · 잔여/초과 | 1칸 라벨에 날짜를 넣을지, 제목으로 올릴지 |
| 반반차(0.25)가 들어와도 칸만 늘리는 구조 | 안내 세 줄의 문장 |
