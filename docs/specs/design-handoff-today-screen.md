# Handoff: SOI DUTY — 오늘 화면 (Today screen)

## Overview
근무시간 기록 Flutter 앱 "SOI DUTY"의 **오늘 화면** 구현 핸드오프. 사용자는 이 화면에서 출근/퇴근을 찍고, 이번 주에 남은 근무시간을 확인한다. 주간/월간 탭은 이번 범위에 포함되지 않으며, 오늘 화면만 먼저 개발한다.

## About the Design Files
이 번들에 포함된 HTML 파일은 **HTML로 만든 디자인 레퍼런스**다. 의도한 외형과 동작을 보여주는 프로토타입이며, 그대로 복사해 쓸 프로덕션 코드가 아니다.

작업은 **이 HTML 디자인을 타깃 코드베이스(Flutter) 환경에서 다시 만드는 것**이다. 기존 프로젝트의 위젯 구조, 상태관리, 테마 패턴을 따르고, 프로젝트가 아직 없다면 Flutter 기본 구조(`StatefulWidget` + `ThemeData` 또는 팀이 쓰는 상태관리)로 구현한다. HTML/CSS를 웹뷰로 띄우는 방식은 의도가 아니다.

## Fidelity
**High-fidelity (hifi).** 색상, 타이포, 간격, 고정 높이가 모두 확정값이다. 아래 문서의 수치를 그대로 사용해 픽셀 단위로 재현한다. HTML의 px 값은 Flutter의 논리 픽셀(dp)로 1:1 대응시킨다.

## Font
**Pretendard** (전체 화면 공통). `pretendard` 패키지 또는 `assets/fonts`에 Pretendard Variable/Static을 넣고 `ThemeData.fontFamily`로 지정한다.
- 사용 weight: 400(Regular), 500(Medium), 600(SemiBold)
- 숫자는 **tabular figures** 필수 (시간 값이 흔들리지 않게). CSS의 `font-feature-settings: 'tnum' 1`에 해당 →
  `TextStyle(fontFeatures: [FontFeature.tabularFigures()])`
- 한글 문장은 `height`(line-height) 1.45~1.55, 큰 숫자는 1.02

## Screens / Views

### 오늘 화면 (단일 화면, 5개 상태)
사용자는 이 화면에서 오늘의 근무를 시작/종료하고 이번 주 잔여 시간을 확인한다.

상태는 5개이며 **모두 같은 레이아웃 골격**을 쓴다. 상태가 바뀌어도 버튼의 Y 좌표가 움직이지 않는 것이 이 화면의 핵심 제약이다.

1. **출근 전** — 출근하기 버튼 활성
2. **근무 중** — 퇴근하기 버튼 활성, 반차 체크박스 노출
3. **퇴근 완료** — 오늘 기록 요약, 버튼 비활성
4. **연차 / 공휴일** — 배지 표시, 버튼 비활성, 되돌리기 링크
5. **첫 주 예외** — 목표 없이 실적만 표시 (설치 후 최초 1회)

## Interactions & Behavior
- **주 버튼 탭**: 출근 전 → 근무 중 → 퇴근 완료. 비활성 상태(퇴근 완료, 연차/공휴일)에서는 아무 일도 일어나지 않는다.
- **연차/공휴일 선택** (출근 전 상태에서만): 선택하면 즉시 상태 4로 전환 — 버튼이 비활성이 되고 배지가 뜬다. 같은 항목 재탭 또는 "되돌리기" 탭 시 출근 전 상태로 복귀.
- **반차 체크** (근무 중 상태): 점심 1h 공제가 빠지므로 **퇴근 예상 시각과 이번 주 남은 시간이 함께 바뀐다**. 예: 17:34 → 13:34, 7h 22m → 3h 22m, 근거 문구 "28h 38m / 32h · 반차 2회".
- **시간 수정하기** (퇴근 완료): 오늘 기록 수정 시트로 이동.
- **빵꾸 리스트 행 탭**: 그 날짜의 기록 입력 시트로 이동.
- 애니메이션: 진행 바 `width .4s ease`, 체크박스/칩 배경·테두리 `.15s`, 버튼 배경 `.2s` + pressed `scale(.985~.99)` `.1s`. 그 외 화면 전환 애니메이션은 없다.
- **레이아웃 불변 규칙 (가장 중요)**: 상태 블록 104, 버튼 56, 보조 슬롯 38(+margin 12)은 다섯 상태에서 동일하다. 내용이 짧아도 높이를 줄이지 않는다.

## 계산 규칙 (도메인)
- 주 기준 근무시간 **40h**, 반차 1회당 목표 4h 차감, 연차/공휴일 1일당 목표 8h 차감 → 근거 문구의 분모가 바뀐다 (예: 36h, 32h, 28h).
- 하루 근무 인정시간 = 퇴근 − 출근 − 점심 1h. **반차인 날은 점심 공제 없음.**
- 퇴근 예상 시각 = 출근시각 + (오늘 남은 목표 + 점심 공제).
- 주말 근무는 주 40시간 집계에 포함하지 않는다.
- **첫 주 예외**: 첫 기록일이 그 주의 월요일이 아니면 **그 주만** 잔여 계산을 하지 않는다. 목표 없이 실적만 표시하고, 없는 데이터를 8h 등으로 추측해 채우지 않는다. 다음 주부터 정상 계산. 이 분기는 설치 후 한 번만 탄다.
  - 구현 주의: 첫 기록일(월~일 중 어느 요일인지)을 저장해 두고, 그 주의 계산에서만 목표/잔여/진행바를 비활성화한다.

## State Management
필요한 상태:
- `phase`: `before` | `working` | `done`
- `dayType`: `null` | `annual`(연차) | `holiday`(공휴일) — `before`일 때만 유효, 값이 있으면 화면은 상태 4
- `isHalfDay`: bool (근무 중 반차 체크)
- `clockInAt`, `clockOutAt`: DateTime?
- `weekWorkedMinutes`, `weekGoalMinutes`, `unrecordedDays: List<Date>`
- `firstWeekException`: bool (파생값 — 첫 기록일 요일로 계산)

전이:
- 출근하기 → `phase = working`, `clockInAt = now`
- 퇴근하기 → `phase = done`, `clockOutAt = now`, 주간 누적 갱신
- 연차/공휴일 선택 → `dayType` 설정 (버튼 비활성), 되돌리기 → `dayType = null`
- 자정 넘어가면 다음 날 `phase = before`로 초기화

## Assets
로고는 **투명 배경 PNG로만 관리**한다. 배경색이 필요한 곳(스플래시, 앱 아이콘)은 **앱에서 배경을 채우고 그 위에 투명 로고를 얹는다** — 배경이 구워진 이미지는 쓰지 않는다.

- `logo-transparent.png` — 마크 + SOI DUTY 워드마크 (투명). 스플래시용
- `mark-transparent.png` — 마크만 (투명). 앱 아이콘, 헤더용

적용 방법:
- 스플래시: `Container(color: Color(0xFF1B473A))` 위에 `Image.asset('logo-transparent.png', width: 252)` 중앙 배치
- 앱 아이콘: `#1B473A` 정사각형 캔버스 위에 **워드마크까지 포함한 `logo-transparent.png`를 78% 크기로 중앙 배치**해서 iOS/Android 아이콘 세트를 생성 (`flutter_launcher_icons`의 `adaptive_icon_background: "#1B473A"` + `adaptive_icon_foreground`에 투명 로고). 작은 사이즈(36px 이하)에서는 워드마크를 뺀 `mark-transparent.png`를 쓴다.
- 워드마크는 원본이 흰색이므로 밝은 배경 위에는 올리지 않는다. 밝은 배경에서는 마크 + Pretendard 텍스트("SOI DUTY", w600, letter-spacing 0.12em, `#2C5A4C`)로 조판한다.
- 36px 이하에서는 마크 안의 "12h / 40h" 글자가 뭉개진다 — 작은 사이즈용 단순화 버전이 별도로 필요하다. 벡터(SVG/PDF) 원본이 있으면 더 선명하다.
