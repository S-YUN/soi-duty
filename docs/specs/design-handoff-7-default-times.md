# Brief 7 · 기본 출퇴근 시각

- 작성일: 2026-11-24
- 디자인 시안: https://claude.ai/artifact/7UeyVHwUG4oMZvUYLWPW3K#artboard-Brief7 (보드 7종)
- 프로토타입: 같은 캔버스의 Main, `brief7` 스위치를 켠 상태

## 1. 배경

기록이 없는 날에 출근·퇴근 시각을 넣으려고 시각 줄을 누르면, 휠이 지금은 항상 08:00(출근) / 17:00(퇴근)부터 보인다. 근무 시간대가 사람마다 달라서, 이 처음 값을 설정에서 각자 바꿀 수 있게 한다.

## 2. 범위

### 바뀌는 것
- 설정 화면에 "기록" 묶음과 "기본 출퇴근 시각" 줄 추가
- "기본 출퇴근 시각" 바텀시트 추가
- 기록 시트에서 **값이 비어 있는** 출근·퇴근 줄을 눌렀을 때 휠의 처음 값: 저장된 기본 출근 / 기본 퇴근 시각

### 바뀌지 않는 것
- 이미 저장된 기록 (기본값을 바꿔도 과거 기록은 그대로)
- 값이 이미 있는 시각 줄을 눌렀을 때 (그 값부터 보임, 지금과 같음)
- 오늘 화면의 "출근하기" / "퇴근하기" (지금 시각으로 찍힘, 지금과 같음)
- 시간 출장 시트의 처음 값 (그날 출근 시각, 없으면 09:00부터 3시간)
- 퇴근 알림, 주 40시간 계산, 점심 공제

## 3. 설정 화면

묶음 순서: 캘린더 → 알림 → **기록** → 연차 → 수당 → 데이터 → 앱 정보

| 요소 | 내용 |
|---|---|
| 묶음 제목 | 기록 |
| 줄 제목 | 기본 출퇴근 시각 |
| 줄 값 | `HH:MM–HH:MM` (예: `08:00–17:00`), 연차·시급 줄에 값이 있을 때와 같은 스타일(15 · 600 · 강조색) + 오른쪽 꺾쇠 |
| 묶음 아래 설명 | 기록이 없는 날에 시각을 넣을 때 처음 보이는 값이에요 |

- 줄 전체를 누르면 시트가 열린다.
- 이 값은 "사용 안 함" 상태가 없다. 항상 값이 있고, 처음 설치했을 때는 08:00–17:00.
- 시각 사이 기호는 시간 출장 칩과 같은 en dash(–), 띄어쓰기 없음.

## 4. 기본 출퇴근 시각 시트

시간 출장 시트의 구성(타일 2개 + 휠 + 안내 줄 + 버튼)을 그대로 재사용한다.

| 요소 | 내용 |
|---|---|
| 제목 | 기본 출퇴근 시각 |
| 설명 | 기록이 없는 날에 시각을 넣을 때 처음 보이는 값이에요. |
| 타일 라벨 | 출근 / 퇴근 |
| 휠 | 오전·오후 / 시(1–12) / 분(00–59, 1분 단위) |
| 안내 줄 (정상) | 이미 넣은 기록은 바뀌지 않아요 |
| 안내 줄 (오류) | 퇴근이 출근보다 늦어야 해요 |
| 버튼 | 저장 |

동작:
- 열면 저장된 값이 타일에 채워지고, **출근 타일이 선택된 상태**로 시작한다.
- 타일을 누르면 그 타일이 선택되고(값 강조색 · 600, 아래 2px 강조색 밑줄) 휠이 그 값으로 맞춰진다.
- 퇴근 ≤ 출근이면 오류 문구(#A8503F)를 보이고 저장 버튼을 끈다(시간 출장 시트의 꺼진 버튼과 같은 모양).
- 저장하면 두 값을 저장하고 시트를 닫는다. 토스트 없음.
- 되돌리기 링크는 두지 않는다. 08:00–17:00으로 돌아가려면 휠로 다시 고른다.
- 바깥(스크림)을 누르면 저장하지 않고 닫는다.

## 5. 기록 시트에 적용

- 출근 줄이 비어 있을 때(`--:--`) 누르면 휠이 **기본 출근 시각**부터, 퇴근 줄이 비어 있을 때 누르면 **기본 퇴근 시각**부터 보인다.
- 지금 코드에서 08:00 / 17:00이 상수로 쓰이는 곳을 설정 값으로 바꾸면 된다. 다른 로직은 그대로.

## 6. 데이터

- 저장 값: 기본 출근 시각, 기본 퇴근 시각 (각각 `HH:MM`)
- 기본값: `08:00`, `17:00`
- 저장 위치: 다른 설정 값(시작 요일, 시급 등)과 같은 곳

## 7. 디자인에서 정하지 않은 것 (구현 전에 결정 필요)

1. **내보내기·가져오기**: 설정 화면 문구가 "기록과 설정을 파일 하나로 저장해요"라서, 이 값도 백업 파일에 포함하는 게 자연스럽다. 포함한다면 예전 파일(값 없음)을 가져올 때는 08:00 / 17:00으로 둔다.
2. **자정을 넘기는 근무**: 지금 규칙은 퇴근이 출근보다 늦어야 저장된다. 야간 근무(예: 22:00–06:00)는 지원하지 않는다.

## 8. 확인할 화면 (시안 보드 번호)

1. 설정 · 처음: 기록 묶음, 08:00–17:00
2. 시트 · 출근 선택
3. 시트 · 퇴근이 더 이름: 오류 문구, 저장 꺼짐
4. 설정 · 바꾼 뒤: 09:30–18:30
5. 시트 · 다시 열기: 저장한 값(09:30–18:30)이 채워짐. 연 뒤에 퇴근 타일을 누른 모습 (열 때는 항상 출근 선택)
6. 기록 없는 날 · 출근 줄 누름: 09:30부터
7. 기록 없는 날 · 퇴근 줄 누름: 18:30부터

## 10. 구현하며 정한 것 (2026-11-24)

- **§7-1 백업**: 포함한다. `settings.defaultClockIn` · `defaultClockOut`(`HH:mm`). **파일 형식 버전은 3 그대로** — 올리면 업데이트 안 한 앱이
  새 파일을 통째로 거부하고, 그대로 두면 옛 앱은 이 두 키만 무시한다. 값이 없는 파일을 가져오면 08:00 / 17:00으로 돌아간다.
- **§7-2 자정 넘김**: 지원하지 않는다(기록과 같은 규칙). 퇴근 ≤ 출근은 시트에서 저장이 꺼지고, 저장소·백업에서는 그런 쌍을 없는 것으로 읽는다.
- **저장**: `Settings` 테이블 키 `default_clock_in` · `default_clock_out`. 정한 적 없으면 행이 없고 `WorkRules`의 08:00 / 17:00을 쓴다
  (`AppSettings.defaultClockTimes(rules)`). 한 쌍으로만 다룬다 — 하나만 있거나 못 읽으면 둘 다 없는 것.
- **시트**: 시간 출장 시트의 골격을 `TimeRangeSheet`로 빼 두 시트가 같이 쓴다. 다른 건 문구와 안내 줄(13.5 subtle · 최소 높이 22)뿐.
