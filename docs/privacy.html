소이듀티 개인정보처리방침

SOI DUTY Privacy Policy · 시행일 2026년 10월 25일 (최초 시행 2026년 9월 26일)

소이듀티는 어떤 개인정보도 수집하지 않습니다. 모든 기록은 사용자의 기기 안에만 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다.

1. 수집하는 개인정보

없습니다. 소이듀티는 회원가입, 로그인, 계정 생성을 요구하지 않으며 이름·이메일·전화번호·위치 등 어떠한 개인정보도 수집하지 않습니다.

2. 앱이 저장하는 정보

사용자가 직접 입력한 다음 정보가 기기 내부 저장소에만 보관됩니다.

  • 날짜별 출근·퇴근 시각
  • 근무 유형 (반차·연차·공휴일·출장 표시)과 시간공제
  • 최초 기록일
  • 설정값 — 월간 캘린더 시작 요일, 연도별 총 연차 일수, 시급(선택 입력), 마지막 내보내기 날짜

이 정보는 개인을 식별할 수 있는 형태가 아니며, 아래 3항의 "내보내기"로 사용자가 직접 보내는 경우를 제외하면 앱 외부로 나가지 않습니다. 시급과 총 연차는 원할 때만 입력하는 선택 항목이며, 입력하지 않아도 다른 기능은 그대로 쓸 수 있습니다.

3. 정보의 외부 전송

없습니다. 소이듀티는 서버를 운영하지 않습니다. 앱은 인터넷 접속 권한 (android.permission.INTERNET)조차 요청하지 않으므로, 기록을 외부로 전송하는 것이 기술적으로 불가능합니다.

단, 앱 안의 [설정 → 데이터 → 내보내기]를 누르면 2항의 정보를 담은 파일(JSON) 하나가 만들어지고 운영체제의 공유 창이 열립니다. 파일을 어디로 보낼지(파일 앱, 클라우드 드라이브, 메신저 등)는 사용자가 그 창에서 직접 고르며, 개발자에게 전송되는 일은 없습니다. [가져오기]는 사용자가 운영체제의 파일 선택 창에서 고른 파일 하나만 읽습니다. 내보내기용 임시 파일은 기기 안 임시 폴더에 만들어지고 다음 내보내기 때 지워집니다.

[설정 → 앱 정보 → 개인정보 처리방침]은 기기의 웹 브라우저로 이 페이지를 여는 것이며, 앱 자체는 네트워크에 접속하지 않습니다.

4. 운영체제 백업에 관한 안내

안드로이드는 앱 데이터를 사용자의 구글 계정에, iOS는 사용자의 iCloud(또는 컴퓨터)에 자동으로 백업하는 기능을 제공합니다. 이 기능이 켜져 있는 경우, 소이듀티의 기록과 설정값도 사용자 본인의 백업에 포함될 수 있습니다.

이는 운영체제가 제공하는 기능이며, 백업된 데이터는 사용자 본인의 계정에 보관됩니다. 개발자는 이 데이터에 접근할 수 없습니다.

원하지 않는 경우 안드로이드는 [설정 → 시스템 → 백업], iOS는 [설정 → Apple 계정 → iCloud → iCloud 백업]에서 끌 수 있습니다.

5. 제3자 제공 및 광고·분석 도구

없습니다. 수집하는 정보가 없으므로 제3자에게 제공하는 정보도 없습니다. 광고 SDK, 분석 도구, 크래시 리포팅 도구를 사용하지 않습니다.

6. 앱이 요청하는 권한

없습니다. 카메라·위치·연락처·저장소 등 어떠한 기기 권한도 요청하지 않습니다. 내보내기·가져오기는 운영체제의 공유 창과 파일 선택 창을 통해 사용자가 고른 파일에만 접근하므로 별도의 저장소 권한이 필요 없습니다.

7. 데이터 보관 및 삭제

기록은 사용자가 직접 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다. 앱을 삭제하면 저장된 기록도 함께 삭제됩니다.

개별 기록은 앱 안의 시간 수정 화면에서 언제든 지울 수 있습니다. 시급과 총 연차는 설정의 "사용 안 함으로 되돌리기"로 지울 수 있습니다. 내보낸 파일은 사용자가 저장한 위치에 남으므로, 필요 없으면 그곳에서 직접 삭제해 주세요.

개발자가 보관하는 사용자 데이터가 없으므로, 별도의 삭제 요청 절차는 필요하지 않습니다.

8. 아동의 개인정보

소이듀티는 연령과 무관하게 어떠한 개인정보도 수집하지 않습니다.
